邊際函數與需求彈性

這一節沒有新的微分技巧，只是把「導數」換成商管的說法：邊際 = 微分。會微分多項式，再記住五個名詞和一條彈性公式，這一節就拿下了。

先認識四個主角

題目一定是一家公司在賣東西。$x$ 是賣出（生產）的數量，$p$ 是每一個的單價。

名稱記號怎麼來的
需求方程式$p = f(x)$題目給。價格越低賣越多，所以通常是遞減的
成本函數$C(x)$題目給。做 $x$ 個總共要花多少
收益函數$R(x) = p\cdot x$單價 × 數量，把 $p$ 換成需求方程式
利潤函數$P(x) = R(x) - C(x)$收益 − 成本

$R(x)$ 是「收益」不是「利潤」。小寫 $p$ 是單價，大寫 $P$ 是利潤，寫的時候大小寫要分清楚。

邊際成本就是 C′(x)

「邊際成本」問的是：現在已經做了 $x$ 個，再多做 1 個，大約要多花多少錢？

真正多花的錢是 $C(x+1) - C(x)$，但這樣算很麻煩。因為「多 1 個」相對整個產量很小，直接用切線斜率 $C'(x)$ 來估就很準：

$$C'(x) \approx C(x+1) - C(x) = \text{第 } x+1 \text{ 個的實際成本}$$

拖曳下面的圖，比較兩個數字有多接近（這是指定題 #13 的成本函數）：

邊際收益與邊際利潤

同樣的想法套到收益和利潤上：

邊際成本 $C'(x)$：多做 1 個，成本大約增加多少
邊際收益 $R'(x)$：多賣 1 個，收益大約增加多少
邊際利潤 $P'(x) = R'(x) - C'(x)$：多賣 1 個，利潤大約增加多少

邊際利潤的正負號直接告訴老闆該怎麼做：

  • $P'(x) \gt 0$：多賣 1 個利潤還會增加，值得增產。
  • $P'(x) \lt 0$：多賣 1 個利潤反而減少，應該減產。
  • $P'(x) = 0$：也就是 $R'(x) = C'(x)$，利潤在這裡達到最高點（4.4 節會再用到）。

某公司在產量 500 時，邊際收益是每單位 3 美元，邊際成本是每單位 2.8 美元。應該增產嗎？

邊際利潤 $P' = R' - C' = 3 - 2.8 = 0.2 \gt 0$，再多做一點利潤還會增加。這是課本 3.4 的觀念題。

平均成本與邊際平均成本

$$\bar{C}(x) = \frac{C(x)}{x} \qquad\text{（每一個平均攤到多少成本）}$$

邊際平均成本就是把平均成本再微分一次：$\bar{C}'(x)$。

「邊際成本 $C'(x)$」和「邊際平均成本 $\bar{C}'(x)$」是兩個不同的東西。看到平均兩個字，要先除以 $x$，再微分，順序不能反過來。

$\bar{C}'(x)$ 的正負號代表：繼續增產，平均每個的成本是在下降（負）還是上升（正）。

需求彈性 E(p)

彈性問的是：價格漲 1%，需求量會掉大約百分之幾？掉超過 1% 叫「有彈性」（客人很敏感），掉不到 1% 叫「無彈性」（客人不太在意）。

算彈性時，需求方程式要寫成「數量是價格的函數」$x = f(p)$（跟前面 $p = f(x)$ 反過來）。

$$E(p) = -\,\frac{p\,f'(p)}{f(p)}$$

$E(p) \gt 1$：有彈性（elastic）　　$E(p) = 1$：單一彈性（unitary）　　$E(p) \lt 1$：無彈性（inelastic）

因為 $f'(p)$ 是負的（越貴賣越少），前面那個負號是為了讓 $E$ 變成正數。

彈性和收益的關係（必考）

需求條件價格調漲一點價格調降一點
有彈性$E(p) \gt 1$收益減少收益增加
無彈性$E(p) \lt 1$收益增加收益減少
單一彈性$E(p) = 1$收益幾乎不變（此時收益最大）

記法：有彈性時，價格和收益反方向走；無彈性時，同方向走。下面是指定題 #37 的需求，拖曳價格看看收益怎麼變：

  1. 把需求方程式整理成 $x = f(p)$。
  2. 微分求 $f'(p)$。
  3. 代公式 $E(p) = -\dfrac{p\,f'(p)}{f(p)}$ 並化簡。
  4. 把題目的 $p$ 代進去，跟 1 比大小，下結論。

暖身例題：需求方程式 $x = -\tfrac54 p + 20$，求 $p = 10$ 時的彈性。

$f(p) = -\tfrac54 p + 20$，$f'(p) = -\tfrac54$，所以

$$E(p) = -\frac{p\cdot\left(-\tfrac54\right)}{-\tfrac54 p + 20} = \frac{\tfrac54 p}{20 - \tfrac54 p} \qquad E(10) = \frac{12.5}{7.5} = \frac53 \gt 1$$

所以 $p = 10$ 時需求有彈性。

某商品在目前價格下 $E(p) = 0.4$。老闆想增加收益，應該？

$E \lt 1$ 是無彈性，價格和收益同方向：漲價收益增加。收益最大是在 $E = 1$。

LED 電視的邊際成本、收益、利潤

某款 LED 電視每週的需求方程式為 $p = 600 - 0.05x$（$0 \le x \le 12000$），$p$ 是批發單價（美元），$x$ 是需求量。每週生產 $x$ 台的總成本為

$$C(x) = 0.000002x^3 - 0.03x^2 + 400x + 80000$$

(a) 求收益函數 $R$ 與利潤函數 $P$。
(b) 求邊際成本 $C'$、邊際收益 $R'$、邊際利潤 $P'$。
(c) 計算 $C'(2000)$、$R'(2000)$、$P'(2000)$ 並解釋。
(d) 畫出 $C$、$R$、$P$ 的圖形，並用圖形解釋 (b)(c)。

提示

收益 = 單價 × 數量，把 $p$ 換成 $600 - 0.05x$。利潤 = 收益 − 成本，減的時候成本要整個括起來，每一項都要變號。

(a) 收益函數

$$R(x) = p\cdot x = (600 - 0.05x)\,x = 600x - 0.05x^2$$

(a) 利潤函數

$$\begin{aligned}P(x) &= R(x) - C(x)\\ &= 600x - 0.05x^2 - \left(0.000002x^3 - 0.03x^2 + 400x + 80000\right)\\ &= -0.000002x^3 - 0.02x^2 + 200x - 80000\end{aligned}$$

注意 $-0.05x^2 - (-0.03x^2) = -0.02x^2$，以及 $600x - 400x = 200x$。

(b) 三個都微分

$$\begin{aligned}C'(x) &= 0.000006x^2 - 0.06x + 400\\ R'(x) &= 600 - 0.1x\\ P'(x) &= -0.000006x^2 - 0.04x + 200\end{aligned}$$

檢查：$P' = R' - C'$ 應該成立。$600 - 400 = 200$ ✓，$-0.1x + 0.06x = -0.04x$ ✓。

(c) 代入 x = 2000

先算 $2000^2 = 4{,}000{,}000$，所以 $0.000006 \times 4{,}000{,}000 = 24$。

$$\begin{aligned}C'(2000) &= 24 - 120 + 400 = 304\\ R'(2000) &= 600 - 200 = 400\\ P'(2000) &= -24 - 80 + 200 = 96\end{aligned}$$

解釋：產量已經是 2000 台時，再多做 1 台（第 2001 台）成本大約增加 304 美元，收益大約增加 400 美元，所以利潤大約增加 96 美元。

(d) 圖形

$R(x) = 600x - 0.05x^2$，$P(x) = -0.000002x^3 - 0.02x^2 + 200x - 80000$；$C'(2000) = 304$，$R'(2000) = 400$，$P'(2000) = 96$。

LED 電視的邊際平均成本

沿用 #13 的成本函數 $C(x) = 0.000002x^3 - 0.03x^2 + 400x + 80000$。

(a) 求平均成本函數 $\bar{C}$。
(b) 求邊際平均成本函數 $\bar{C}'$。
(c) 計算 $\bar{C}'(5000)$ 與 $\bar{C}'(10000)$ 並解釋。
(d) 畫出 $\bar{C}$ 的圖形。

提示

先把 $C(x)$ 每一項都除以 $x$，最後一項會變成 $\dfrac{80000}{x} = 80000x^{-1}$，再微分。

(a) 每一項除以 x

$$\bar{C}(x) = \frac{C(x)}{x} = 0.000002x^2 - 0.03x + 400 + \frac{80000}{x}$$

(b) 微分

$\dfrac{80000}{x} = 80000x^{-1}$，微分是 $-80000x^{-2}$：

$$\bar{C}'(x) = 0.000004x - 0.03 - \frac{80000}{x^2}$$

(c) 代入

$$\begin{aligned}\bar{C}'(5000) &= 0.02 - 0.03 - \frac{80000}{25{,}000{,}000} = -0.01 - 0.0032 = -0.0132\\[4pt] \bar{C}'(10000) &= 0.04 - 0.03 - \frac{80000}{100{,}000{,}000} = 0.01 - 0.0008 = 0.0092\end{aligned}$$

解釋：產量 5000 台時邊際平均成本是負的，表示再增產，平均每台成本還在下降；產量 10000 台時是正的，表示再增產，平均每台成本會上升。

(d) 圖形

$\bar{C}(x) = 0.000002x^2 - 0.03x + 400 + \dfrac{80000}{x}$；$\bar{C}'(x) = 0.000004x - 0.03 - \dfrac{80000}{x^2}$；$\bar{C}'(5000) = -0.0132$，$\bar{C}'(10000) = 0.0092$。

DVD 出租的需求彈性

影片出租店估計，DVD 租金 $p$（美元）和每天出租量 $x$（千片）的關係是

$$x = \frac23\sqrt{36 - p^2} \qquad (0 \le p \le 6)$$

目前租金是每片 2 美元。

(a) 在這個價格下，需求是有彈性還是無彈性？
(b) 如果調漲租金，收益會增加還是減少？

提示

$f(p) = \tfrac23(36 - p^2)^{1/2}$，用連鎖律微分。裡面 $36 - p^2$ 的微分是 $-2p$。

微分 f(p)

$$f'(p) = \frac23\cdot\frac12(36 - p^2)^{-1/2}\cdot(-2p) = \frac{-2p}{3\sqrt{36 - p^2}}$$

代彈性公式並化簡

$$E(p) = -\frac{p\,f'(p)}{f(p)} = \frac{p\cdot\dfrac{2p}{3\sqrt{36 - p^2}}}{\dfrac23\sqrt{36 - p^2}} = \frac{2p^2}{3\sqrt{36-p^2}}\cdot\frac{3}{2\sqrt{36-p^2}} = \frac{p^2}{36 - p^2}$$

兩個根號相乘剛好變成 $36 - p^2$，$\tfrac23$ 也約掉了。

(a) 代入 p = 2

$$E(2) = \frac{4}{36 - 4} = \frac{4}{32} = \frac18 = 0.125 \lt 1$$

所以需求無彈性。

(b) 判斷收益

無彈性時，價格和收益同方向變動。調漲租金，出租量只會少一點點，收益會增加。

(a) $E(2) = \tfrac18 \lt 1$，無彈性。(b) 調漲租金，收益增加。

這一節的題目有固定句型。算完 $C'(2000) = 304$ 之後，一定要補一句解釋：「生產第 2001 台的成本大約是 304 美元」。彈性題最後也要寫出「有彈性／無彈性」和「收益增加／減少」的結論，只寫數字會被扣分。
