二階導數：凹性與反曲點

4.1 用 $f'$ 看曲線「往上還是往下」。這一節多微分一次，用 $f''$ 看曲線「往哪邊彎」。會求 $f''$、會畫符號圖，這一節的題目就都做得出來。

凹向上、凹向下是什麼

凹向上：開口朝上，像一個碗 ∪，裝得住水。
凹向下：開口朝下，像倒蓋的碗 ∩，水會流掉。

怎麼用微分判斷？看切線斜率的變化。拖曳下面的圖，注意橘色切線是怎麼轉的：

「斜率越來越大」就是 $f'$ 在遞增。而 4.1 學過：一個函數在遞增，它的導數是正的。$f'$ 的導數就是 $f''$，所以：

在某個區間上 $f''(x) \gt 0$ → $f'$ 遞增 → 圖形凹向上 ∪
在某個區間上 $f''(x) \lt 0$ → $f'$ 遞減 → 圖形凹向下 ∩

$f''$ 叫做二階導數，就是把 $f$ 微分兩次（3.5 節）。記法：$f''$ 是正的，像笑臉 ∪；是負的，像哭臉 ∩。

凹性和遞增遞減是兩回事

$f'$ 管「上升或下降」，$f''$ 管「彎的方向」，兩個互不相干，所以一共有四種組合：

不要把「凹向上」想成「上升」。凹向上的曲線可以正在下降（左下那張圖），凹向下的曲線也可以正在上升（右上那張圖）。

在某個區間上 $f'(x) \gt 0$ 而且 $f''(x) \lt 0$。這段圖形長什麼樣子？

$f' \gt 0$ 是上升。$f'' \lt 0$ 表示斜率在變小，所以越來越平，是 ∩ 形的左半邊。

怎麼求凹性區間

做法和 4.1 求遞增遞減一模一樣，只是把 $f'$ 換成 $f''$：

  1. 微分兩次，求出 $f''(x)$。
  2. 找出 $f''(x) = 0$ 或 $f''(x)$ 不存在的 $x$，用這些點把數線切成幾段。
  3. 每一段挑一個數代進 $f''$，看正負，畫出 $f''$ 的符號圖。
  4. 正的那幾段凹向上，負的那幾段凹向下。

例：$f(x) = x^3 - 3x^2 + 1$（上面那張圖的函數）。

$$f'(x) = 3x^2 - 6x \qquad f''(x) = 6x - 6 = 6(x - 1)$$

$f''(x) = 0$ 得到 $x = 1$。左邊代 $x = 0$：$f''(0) = -6 \lt 0$；右邊代 $x = 2$：$f''(2) = 6 \gt 0$。

結論：在 $(-\infty, 1)$ 凹向下，在 $(1, \infty)$ 凹向上。

反曲點

圖形上凹性改變的那一點叫做反曲點（inflection point）。也就是 $f''$ 在那一點的左右兩邊正負號不同。

上面的例子裡，$f''$ 在 $x = 1$ 由負變正，所以有反曲點。反曲點是「一個點」，要寫出座標：$f(1) = 1 - 3 + 1 = -1$，反曲點是 $(1, -1)$。

  1. 求 $f''(x)$，找出定義域裡 $f''(x) = 0$ 或 $f''(x)$ 不存在的 $x$。這些只是候選人。
  2. 畫 $f''$ 的符號圖，檢查每個候選人的左右兩邊有沒有變號。
  3. 有變號的才是反曲點，把 $x$ 代回原函數 $f$ 求 $y$ 座標。

$f''(c) = 0$ 不保證是反曲點，一定要檢查兩邊有沒有變號。看下面的 $f(x) = x^4$：$f''(x) = 12x^2$，$f''(0) = 0$，但是 $0$ 的左右兩邊 $f''$ 都是正的，整條曲線都凹向上，所以沒有反曲點。

另一個要小心的情況：候選人必須在定義域裡。例如 $f(x) = \dfrac1x$，$f''(x) = \dfrac{2}{x^3}$ 在 $x = 0$ 的兩邊確實變號，但是 $f(0)$ 根本不存在，圖形上沒有那個點，所以也沒有反曲點。

算出 $f''(2) = 0$。可以直接說 $(2, f(2))$ 是反曲點嗎？

$f'' = 0$ 只是候選人。反曲點的定義是凹性改變，所以一定要看符號圖有沒有變號。

二階導數檢定法：找相對極值的第二種方法

4.1 的一階導數檢定法是看 $f'$ 在臨界數兩邊的正負。這一節多一個更快的方法：只要把臨界數代進 $f''$ 看正負。

先求出滿足 $f'(c) = 0$ 的臨界數 $c$，再算 $f''(c)$：

$f''(c) \lt 0$ → 那附近是 ∩ 形 → $f(c)$ 是相對極大值
$f''(c) \gt 0$ → 那附近是 ∪ 形 → $f(c)$ 是相對極小值
$f''(c) = 0$ 或不存在 → 檢定失效，改用一階導數檢定法

例：同一個函數 $f(x) = x^3 - 3x^2 + 1$。$f'(x) = 3x(x - 2) = 0$ 得到臨界數 $x = 0$ 和 $x = 2$。$f''(x) = 6x - 6$：

  • $f''(0) = -6 \lt 0$，所以 $f(0) = 1$ 是相對極大值。
  • $f''(2) = 6 \gt 0$，所以 $f(2) = -3$ 是相對極小值。

符號容易記反：$f'' \lt 0$ 是極大，$f'' \gt 0$ 是極小。不要死背，想形狀：負的是 ∩，頂端當然是最高點。

一階導數檢定法（4.1）二階導數檢定法（4.2）
做法畫 $f'$ 的符號圖，看臨界數兩邊把臨界數代進 $f''$
優點任何臨界數都能用快，不用畫符號圖
限制要多代幾個數$f''(c) = 0$ 時失效；$f'(c)$ 不存在的臨界數不能用

已知 $f'(3) = 0$，$f''(3) = 5$。那麼 $f(3)$ 是？

$f''(3) = 5 \gt 0$，在 $x = 3$ 附近是 ∪ 形，切線又是水平的，所以是谷底，相對極小值。

應用題：把正負號翻成一句話

這一節的應用題幾乎都是「算完之後解釋意思」。把下面這張表記熟，直接套：

$f'$$f''$可以這樣寫
正正在增加，而且增加得越來越快
正負還在增加，但增加得越來越慢（成長趨緩）
負正在減少，但減少得越來越慢（跌勢趨緩）
負負在減少，而且減少得越來越快

$f'$ 是「變化率」，$f''$ 是「變化率的變化率」。所以反曲點就是變化率最大或最小的時刻：由 ∪ 變 ∩ 的反曲點是成長最快的時候（之後開始趨緩）；由 ∩ 變 ∪ 的反曲點是成長最慢的時候（之後開始加速）。

某公司營收 $R(t)$ 目前滿足 $R'(t) \gt 0$、$R''(t) \lt 0$。哪一句描述正確？

$R' \gt 0$：營收增加中。$R'' \lt 0$：成長率 $R'$ 在變小。合起來就是「成長趨緩」。

指定題

先自己動手算，卡住再一步一步打開解答。

用二階導數檢定法求相對極值（多項式）

求下列函數的相對極值，可以的話請用二階導數檢定法：

$$f(x) = \frac13x^3 - 2x^2 - 5x - 5$$
提示

先解 $f'(x) = 0$ 找臨界數（可以因式分解），再把臨界數一個一個代進 $f''(x)$ 看正負。

求 f′ 並找臨界數

$$f'(x) = x^2 - 4x - 5 = (x - 5)(x + 1)$$

$f'(x) = 0$ 得到 $x = -1$ 和 $x = 5$。

求 f″

$$f''(x) = 2x - 4$$

代入 x = −1

$$f''(-1) = -2 - 4 = -6 \lt 0$$

是 ∩ 形，所以有相對極大值：

$$f(-1) = -\frac13 - 2 + 5 - 5 = -\frac73$$

代入 x = 5

$$f''(5) = 10 - 4 = 6 \gt 0$$

是 ∪ 形，所以有相對極小值：

$$f(5) = \frac{125}{3} - 50 - 25 - 5 = \frac{125}{3} - 80 = -\frac{115}{3}$$

看圖確認

相對極大值 $f(-1) = -\dfrac73$；相對極小值 $f(5) = -\dfrac{115}{3}$。

用二階導數檢定法求相對極值（分式）

求下列函數的相對極值，可以的話請用二階導數檢定法：

$$f(x) = \frac{2x}{x^2 + 1}$$
提示

用除法規則求 $f'$。分母 $(x^2+1)^2$ 永遠是正的，所以只要看分子什麼時候等於 0。$f''$ 要再用一次除法規則，記得先約掉一個 $(x^2+1)$。

除法規則求 f′

上面 $2x$ 微分是 $2$，下面 $x^2+1$ 微分是 $2x$：

$$f'(x) = \frac{2(x^2+1) - 2x\cdot 2x}{(x^2+1)^2} = \frac{2 - 2x^2}{(x^2+1)^2} = \frac{2(1-x)(1+x)}{(x^2+1)^2}$$

分母不會是 0，所以臨界數只有分子為 0 的地方：$x = -1$ 和 $x = 1$。

再用一次除法規則求 f″

上面 $2 - 2x^2$ 微分是 $-4x$；下面 $(x^2+1)^2$ 微分是 $2(x^2+1)\cdot 2x = 4x(x^2+1)$：

$$f''(x) = \frac{-4x(x^2+1)^2 - (2 - 2x^2)\cdot 4x(x^2+1)}{(x^2+1)^4}$$

分子每一項都有 $(x^2+1)$，先約掉一個：

$$f''(x) = \frac{-4x(x^2+1) - 4x(2 - 2x^2)}{(x^2+1)^3} = \frac{4x^3 - 12x}{(x^2+1)^3} = \frac{4x(x^2 - 3)}{(x^2+1)^3}$$

代入 x = 1

$$f''(1) = \frac{4(1)(1 - 3)}{2^3} = \frac{-8}{8} = -1 \lt 0$$

相對極大值：$f(1) = \dfrac{2}{1 + 1} = 1$。

代入 x = −1

$$f''(-1) = \frac{4(-1)(1 - 3)}{2^3} = \frac{8}{8} = 1 \gt 0$$

相對極小值：$f(-1) = \dfrac{-2}{1 + 1} = -1$。

用一階導數檢定法驗算

如果考試時 $f''$ 算不出來，可以改畫 $f'$ 的符號圖，答案一樣。$f'$ 的正負只看分子 $2(1-x)(1+x)$：

在 $x = -1$ 由遞減變遞增（極小），在 $x = 1$ 由遞增變遞減（極大），和上面一致。

相對極大值 $f(1) = 1$；相對極小值 $f(-1) = -1$。

開車成本：證明圖形凹向上

一項針對 2012 年中型房車的研究發現，每英里的平均開車成本（車貸、油錢、保險、保養、折舊，單位：美分）大約是

$$C(x) = \frac{1910.5}{x^{1.72}} + 42.9 \qquad (5 \le x \le 20)$$

其中 $x$ 是每年行駛的里程（單位：千英里）。證明 $C$ 的圖形在 $(5, 20)$ 上凹向上，並說明這個結果代表什麼。

提示

先改寫成 $C(x) = 1910.5\,x^{-1.72} + 42.9$。小數次方一樣用冪次規則：次方搬下來乘，次方再減 1。「證明凹向上」就是證明 $C''(x) \gt 0$。

改寫成次方

$$C(x) = 1910.5\,x^{-1.72} + 42.9$$

微分第一次

$$C'(x) = 1910.5\cdot(-1.72)\,x^{-2.72} = -3286.06\,x^{-2.72}$$

次方 $-1.72 - 1 = -2.72$。

微分第二次

$$C''(x) = -3286.06\cdot(-2.72)\,x^{-3.72} = 8938.0832\,x^{-3.72} = \frac{8938.0832}{x^{3.72}}$$

負負得正。

判斷正負

$x$ 在 $(5, 20)$ 裡是正數，所以 $x^{3.72} \gt 0$，於是 $C''(x) \gt 0$。因此 $C$ 的圖形在 $(5, 20)$ 上凹向上。

解釋

$C'(x) \lt 0$：一年開得越多，每英里的平均成本越低。$C''(x) \gt 0$：$C'$ 在遞增（從很負慢慢接近 0），也就是成本下降的速度越來越慢。多開的那些里程能省下的錢越來越少。

$C''(x) = \dfrac{8938.0832}{x^{3.72}} \gt 0$，所以凹向上。意思是：開越多每英里成本越低，但成本下降得越來越慢。

玻璃公司的利潤預測

一家成立 4 年的玻璃公司因為能源成本上漲，利潤的成長率開始下滑。管理階層決定實施節能措施，總經理估計利潤的成長率會在 4 年內重新開始上升。如果 $t$ 年後公司的利潤（單位：百美元）是

$$P(t) = t^3 - 9t^2 + 40t + 50 \qquad (0 \le t \le 8)$$

判斷總經理的預測是否正確。

提示

「利潤的成長率」是 $P'(t)$。成長率下滑表示 $P'$ 遞減（凹向下），成長率上升表示 $P'$ 遞增（凹向上）。所以要找的是 $P$ 的反曲點。

把題目翻成數學

成長率 = $P'(t)$。「成長率由下滑轉為上升」= $P'$ 由遞減變遞增 = 圖形由凹向下變凹向上 = 反曲點。只要反曲點的 $t$ 小於 4，預測就正確。

微分兩次

$$P'(t) = 3t^2 - 18t + 40 \qquad P''(t) = 6t - 18 = 6(t - 3)$$

畫 P″ 的符號圖

$P''(t) = 0$ 得到 $t = 3$。代 $t = 1$：$P''(1) = -12 \lt 0$；代 $t = 5$：$P''(5) = 12 \gt 0$。

在 $(0, 3)$ 凹向下，在 $(3, 8)$ 凹向上。

反曲點

$$P(3) = 27 - 81 + 120 + 50 = 116$$

反曲點是 $(3, 116)$。

下結論

前 3 年圖形凹向下，利潤成長率 $P'$ 一直在下降；$t = 3$ 之後凹向上，成長率開始回升。$3 \lt 4$，所以成長率確實會在 4 年內重新上升，總經理的預測正確。

$P''(t) = 6t - 18$，反曲點 $(3, 116)$。成長率在 $t = 3$ 年後開始上升，早於 4 年，預測正確。

大眾運輸預算赤字

某都會區運輸局估計，累計預算赤字（單位：十億美元）在有 1.6 億美元紓困方案時是

$$D_1(t) = 0.0275t^2 + 0.081t + 0.07 \qquad (0 \le t \le 3)$$

沒有紓困方案時是

$$D_2(t) = 0.035t^2 + 0.211t + 0.24 \qquad (0 \le t \le 3)$$

$t$ 的單位是年，$t = 0$ 代表 2011 年。令 $D = D_2 - D_1$。

(a) 證明 $D$ 在 $(0, 3)$ 上遞增，並解釋。
(b) 證明 $D$ 的圖形在 $(0, 3)$ 上凹向上，並解釋。

提示

先把兩個式子相減，同類項合併，得到一個新的二次函數 $D(t)$。遞增看 $D'$，凹向上看 $D''$。

先算出 D(t)

$$\begin{aligned}D(t) &= D_2(t) - D_1(t)\\ &= (0.035 - 0.0275)t^2 + (0.211 - 0.081)t + (0.24 - 0.07)\\ &= 0.0075t^2 + 0.13t + 0.17\end{aligned}$$

$D$ 代表「沒有紓困比有紓困多出來的赤字」。

(a) 一階導數

$$D'(t) = 0.015t + 0.13$$

在 $(0, 3)$ 上 $t \gt 0$，所以 $D'(t) \gt 0.13 \gt 0$，$D$ 遞增。

解釋：兩種情況的赤字差距逐年擴大。時間拖得越久，沒有紓困方案的赤字比有紓困方案的多越多。

(b) 二階導數

$$D''(t) = 0.015 \gt 0$$

所以 $D$ 的圖形在 $(0, 3)$ 上凹向上。

解釋：$D'$ 在遞增，表示赤字差距不只是在擴大，而且擴大的速度越來越快。

看圖確認

$D(t) = 0.0075t^2 + 0.13t + 0.17$。(a) $D'(t) = 0.015t + 0.13 \gt 0$，遞增：赤字差距持續擴大。(b) $D''(t) = 0.015 \gt 0$，凹向上：差距擴大得越來越快。

三件事最容易被扣分：一、反曲點要寫成座標 $(x, y)$，$y$ 是代回原函數 $f$，不是代 $f''$。二、$f''(c) = 0$ 之後一定要畫符號圖確認有變號。三、應用題算完要補一句白話解釋，例如「成本下降得越來越慢」「差距擴大得越來越快」。
