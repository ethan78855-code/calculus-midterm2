指數與對數的微分

這兩節只多了四條公式，其中兩條還只是另外兩條加上連鎖律。學會之後，乘法、除法、連鎖律和第 4 章的遞增遞減、極值、反曲點全部照舊，只是函數裡多了 $e^x$ 和 $\ln x$。

函數微分口訣
$e^x$$e^x$微完還是自己
$e^{f(x)}$$e^{f(x)}\cdot f'(x)$整個照抄，再乘指數的微分
$\ln x$$\dfrac{1}{x}$變成倒數
$\ln f(x)$$\dfrac{f'(x)}{f(x)}$裡面的微分放上面，裡面照抄放下面

eˣ 微分之後還是 eˣ

$$\frac{d}{dx}\,e^x = e^x$$

這就是 $e$ 特別的地方：$e^x$ 這條曲線在每一點的切線斜率，剛好等於那一點的高度。高度是 1 的地方斜率是 1，高度是 5 的地方斜率就是 5。

拖曳下面的圖，比較「高度」和「切線斜率」兩個數字：

$e^x$ 不能用冪次規則。冪次規則 $(x^n)' = nx^{n-1}$ 是變數在下面；$e^x$ 的變數在上面，是另一種函數。

$(e^x)' = x\,e^{x-1}$ 是錯的，正確是 $(e^x)' = e^x$。

$f(x) = 5e^x + x^5$，$f'(x)$ 是？

$5e^x$ 是常數倍，微分還是 $5e^x$。$x^5$ 才用冪次規則，得 $5x^4$。兩種函數不要混用規則。

e 的上面是一包東西：連鎖律

考試很少只考 $e^x$，指數通常是 $2x$、$-0.05t$、$-x^2$ 這種式子。這時候要多乘一項：

$$\frac{d}{dx}\,e^{f(x)} = e^{f(x)}\cdot f'(x)$$

口訣：整個 $e^{\cdots}$ 原封不動抄下來，再乘上「指數」的微分。指數本身不會變。

函數指數的微分結果
$e^{2x}$$2$$2e^{2x}$
$e^{-3x}$$-3$$-3e^{-3x}$
$e^{-x^2}$$-2x$$-2x\,e^{-x^2}$
$e^{2t^2+t}$$4t+1$$(4t+1)\,e^{2t^2+t}$
$1500e^{-0.05t}$$-0.05$$1500\cdot(-0.05)\,e^{-0.05t} = -75e^{-0.05t}$

最後一列是 5.6 指定題的型式：$e^{kt}$ 微分就是前面多乘一個 $k$。下圖用滑桿改 $k$，看 $x = 0$ 那一點的切線斜率：

$y = e^{-x^2}$，$y'$ 是？

整個 $e^{-x^2}$ 照抄，再乘指數 $-x^2$ 的微分 $-2x$。指數不會減 1，那是冪次規則。

和乘法、除法規則合用

規則和以前完全一樣，只是其中一塊換成 $e$。

乘法：$y = x^2e^x$。前面 $x^2$，後面 $e^x$：

$$y' = 2x\cdot e^x + x^2\cdot e^x = x\,e^x\,(x + 2)$$

除法：$y = \dfrac{e^x}{1 + e^x}$。上面微分是 $e^x$，下面微分也是 $e^x$：

$$y' = \frac{e^x(1 + e^x) - e^x\cdot e^x}{(1 + e^x)^2} = \frac{e^x}{(1 + e^x)^2}$$

一般冪次規則：$y = (e^t + 2)^{3/2}$。外層是 $\tfrac32$ 次方，裡面 $e^t + 2$ 的微分是 $e^t$：

$$y' = \tfrac32\,(e^t + 2)^{1/2}\cdot e^t$$

微分完一定要把 $e^{\cdots}$ 提出來，像上面的 $x\,e^x(x+2)$。因為 $e^{\cdots}$ 永遠是正的、不可能等於 0，所以解 $y' = 0$ 或判斷正負號時，只要看剩下的那個因式就好。

ln x 的微分是 1/x

$$\frac{d}{dx}\,\ln x = \frac{1}{x} \qquad (x \gt 0)$$

課本寫成 $\dfrac{d}{dx}\ln|x| = \dfrac1x$（$x \ne 0$），公式長得一樣。

從公式可以直接讀出兩件事：$\dfrac1x \gt 0$，所以 $\ln x$ 永遠遞增；再微一次是 $-\dfrac{1}{x^2} \lt 0$，所以圖形永遠凹向下。

ln 裡面是一包東西：連鎖律

$$\frac{d}{dx}\,\ln f(x) = \frac{f'(x)}{f(x)}$$

口訣：畫一條分數線，下面抄裡面那包，上面放它的微分。

函數裡面那包裡面的微分結果
$\ln(x^2+1)$$x^2+1$$2x$$\dfrac{2x}{x^2+1}$
$\ln(3x - 4)$$3x-4$$3$$\dfrac{3}{3x-4}$
$\ln(5x)$$5x$$5$$\dfrac{5}{5x} = \dfrac1x$

第三列的結果和 $\ln x$ 的微分一樣，這不是巧合：$\ln(5x) = \ln 5 + \ln x$，而 $\ln 5$ 是常數，微分是 0。

和乘法、除法規則合用也是同樣的做法：

$$\frac{d}{dx}\big(x\ln x\big) = 1\cdot\ln x + x\cdot\frac1x = \ln x + 1 \qquad\qquad \frac{d}{dx}\Big(\frac{\ln x}{x}\Big) = \frac{\frac1x\cdot x - \ln x\cdot 1}{x^2} = \frac{1 - \ln x}{x^2}$$

$y = \ln(x^3 + 2)$，$y'$ 是？

下面抄裡面的 $x^3+2$，上面放它的微分 $3x^2$。第一個選項忘了乘裡面的微分，是最常見的錯。

先用對數律拆開，再微分

$\ln$ 裡面如果是乘、除、次方、根號，先拆再微會簡單非常多。

例：$y = \ln\big[(x^2+1)(x^3+2)^6\big]$。硬用連鎖律要先對裡面用乘法規則，很長。先拆：

$$y = \ln(x^2+1) + 6\ln(x^3+2) \quad\Rightarrow\quad y' = \frac{2x}{x^2+1} + 6\cdot\frac{3x^2}{x^3+2} = \frac{2x}{x^2+1} + \frac{18x^2}{x^3+2}$$

例：$y = \ln\sqrt{x+1}$。根號是 $\tfrac12$ 次方，搬到前面：

$$y = \tfrac12\ln(x+1) \quad\Rightarrow\quad y' = \frac12\cdot\frac{1}{x+1} = \frac{1}{2(x+1)}$$

只有乘、除、次方能拆。$\ln(x^2 + 1)$ 裡面是加法，不能拆成 $\ln x^2 + \ln 1$，只能直接用公式 4。

對數微分法

有些函數是一長串因式乘除，或是像 $x^x$ 這種底數和指數都有變數的怪東西。直接微很痛苦，可以先兩邊取 $\ln$。

  1. 兩邊取 $\ln$：$\ln y = \ln(\cdots)$。
  2. 用對數律把右邊拆成一項一項相加減。
  3. 兩邊對 $x$ 微分。左邊 $\ln y$ 的微分是 $\dfrac{y'}{y}$（$y$ 是 $x$ 的函數，所以用公式 4）。
  4. 兩邊乘上 $y$，再把 $y$ 換回原來的式子。

例：$y = x^x$（$x \gt 0$）。冪次規則和指數規則都不能用，因為底數和指數都在變。

$$\ln y = x\ln x \quad\Rightarrow\quad \frac{y'}{y} = \ln x + 1 \quad\Rightarrow\quad y' = y\,(\ln x + 1) = x^x(\ln x + 1)$$

右邊 $x\ln x$ 的微分用乘法規則，上一段剛算過是 $\ln x + 1$。

接上第 4 章：分析 f(x) = xe⁻ˣ

考試範圍同時有第 4 章和第 5 章，所以很可能要你對含 $e$ 的函數找極值和反曲點。步驟和第 4 章一模一樣。

一階導數（乘法規則，$e^{-x}$ 的微分是 $-e^{-x}$）：

$$f'(x) = 1\cdot e^{-x} + x\cdot(-e^{-x}) = (1 - x)\,e^{-x}$$

$e^{-x}$ 永遠是正的，所以 $f'(x) = 0$ 只有 $x = 1$，而且 $f'$ 的正負號完全由 $(1 - x)$ 決定：

先升後降，所以 $x = 1$ 有相對極大值 $f(1) = e^{-1} = \dfrac1e \approx 0.368$。

二階導數（對 $(1-x)e^{-x}$ 再用一次乘法規則）：

$$f''(x) = (-1)\cdot e^{-x} + (1 - x)\cdot(-e^{-x}) = (x - 2)\,e^{-x}$$

凹性在 $x = 2$ 改變，所以反曲點是 $\left(2,\ 2e^{-2}\right) \approx (2,\ 0.271)$。

某函數的導數是 $f'(x) = (x^2 - 4)\,e^{3x}$。臨界數有哪些？

$e^{3x}$ 永遠大於 0，不會讓 $f'$ 變成 0。只要解 $x^2 - 4 = 0$，得 $x = \pm 2$。

  1. 算 $2e^{-2}$：按 2 × eˣ ( (−) 2 ) =，得 0.2707。負的指數要用括號包起來。
  2. 算 $\dfrac{1}{e}$：按 eˣ ( (−) 1 ) =，得 0.3679。$\dfrac1e$ 就是 $e^{-1}$。
  3. 算 $e^{-1/2}$：按 eˣ ( (−) 1 ÷ 2 ) =，得 0.6065。
  4. 算 $\ln 8$：按 ln 8 =，得 2.0794。ln 和 log 是不同的鍵，微積分幾乎都用 ln。
  5. 答案先保留 $\dfrac1e$、$\ln 8$ 這種精確寫法，題目要小數時最後才按計算機。

例題

這兩節沒有指定題，但都在考試範圍裡，5.6 的指定題也要用到這些微分。由淺到深共六題。

例題 1：逐項微分

求 $f(x) = 3e^{2x} - 4e^{-x} + x^2$ 的導數。

每一項各自處理

$3e^{2x}$：照抄，再乘指數的微分 2，得 $6e^{2x}$。
$-4e^{-x}$：照抄，再乘指數的微分 $-1$，得 $+4e^{-x}$。
$x^2$：冪次規則，得 $2x$。

合起來

$$f'(x) = 6e^{2x} + 4e^{-x} + 2x$$

$f'(x) = 6e^{2x} + 4e^{-x} + 2x$

例題 2：乘法規則，找水平切線

$y = x\,e^{-2x}$。(a) 求 $y'$。(b) 圖形在哪一點有水平切線？

提示

水平切線就是斜率為 0，也就是解 $y' = 0$。微分完記得把 $e^{-2x}$ 提出來。

(a) 乘法規則

前面 $x$ 的微分是 1；後面 $e^{-2x}$ 的微分是 $-2e^{-2x}$。

$$y' = 1\cdot e^{-2x} + x\cdot(-2e^{-2x}) = (1 - 2x)\,e^{-2x}$$

(b) 解 y′ = 0

$e^{-2x}$ 不可能是 0，所以只要 $1 - 2x = 0$，得 $x = \tfrac12$。

求那一點的高度

$$y\left(\tfrac12\right) = \tfrac12\,e^{-1} = \frac{1}{2e} \approx 0.184$$

$y' = (1 - 2x)e^{-2x}$；水平切線在 $\left(\tfrac12,\ \tfrac{1}{2e}\right) \approx (0.5,\ 0.184)$。

例題 3：ln 的連鎖律與切線方程式

$f(x) = \ln(x^2 + 4)$。求圖形在 $x = 2$ 的切線斜率與切線方程式。

微分

下面抄 $x^2 + 4$，上面放它的微分 $2x$：

$$f'(x) = \frac{2x}{x^2 + 4}$$

代入 x = 2 得斜率

$$f'(2) = \frac{4}{8} = \frac12$$

切點與切線

切點高度 $f(2) = \ln 8 \approx 2.079$。用點斜式：

$$y - \ln 8 = \tfrac12\,(x - 2) \quad\Rightarrow\quad y = \tfrac12 x - 1 + \ln 8 \approx 0.5x + 1.079$$

斜率 $\tfrac12$；切線 $y = \tfrac12 x - 1 + \ln 8$。

例題 4：含 ln 的函數找相對極值

求 $g(x) = x^2\ln x$ 的相對極值。

提示

定義域是 $x \gt 0$。乘法規則微分後把 $x$ 提出來。解 $\ln x = c$ 的方法是 $x = e^c$。

微分（乘法規則）

$$g'(x) = 2x\cdot\ln x + x^2\cdot\frac1x = 2x\ln x + x = x\,(2\ln x + 1)$$

找臨界數

定義域是 $x \gt 0$，所以 $x$ 這個因式不會是 0。只要解

$$2\ln x + 1 = 0 \quad\Rightarrow\quad \ln x = -\tfrac12 \quad\Rightarrow\quad x = e^{-1/2} \approx 0.607$$

判斷是極大還是極小

也可以用二階導數檢定：$g''(x) = 2\ln x + 3$，代入得 $g''(e^{-1/2}) = -1 + 3 = 2 \gt 0$，所以是相對極小。

求極小值

$$g\left(e^{-1/2}\right) = \left(e^{-1/2}\right)^2\cdot\ln e^{-1/2} = e^{-1}\cdot\left(-\tfrac12\right) = -\frac{1}{2e} \approx -0.184$$

相對極小值 $g\left(e^{-1/2}\right) = -\dfrac{1}{2e} \approx -0.184$；沒有相對極大值。

例題 5：對數微分法

用對數微分法求 $y = (x+1)^2\,(x^2+3)^5$ 的導數。

兩邊取 ln，拆開

$$\ln y = 2\ln(x+1) + 5\ln(x^2+3)$$

兩邊對 x 微分

左邊是 $\dfrac{y'}{y}$，右邊每一項用公式 4：

$$\frac{y'}{y} = \frac{2}{x+1} + \frac{5\cdot 2x}{x^2+3} = \frac{2}{x+1} + \frac{10x}{x^2+3}$$

乘回 y

$$y' = (x+1)^2(x^2+3)^5\left[\frac{2}{x+1} + \frac{10x}{x^2+3}\right]$$

寫到這裡就可以了。想化簡的話，把括號通分後約掉：

$$y' = (x+1)(x^2+3)^4\big[2(x^2+3) + 10x(x+1)\big] = 2(x+1)(x^2+3)^4(6x^2 + 5x + 3)$$

$y' = (x+1)^2(x^2+3)^5\left[\dfrac{2}{x+1} + \dfrac{10x}{x^2+3}\right]$

例題 6：鐘形曲線的極值與反曲點

$f(x) = e^{-x^2/2}$。求遞增、遞減區間，相對極值，以及反曲點。

提示

指數 $-\tfrac{x^2}{2}$ 的微分是 $-x$。求 $f''$ 時要對 $-x\cdot e^{-x^2/2}$ 用乘法規則。

一階導數

$$f'(x) = e^{-x^2/2}\cdot(-x) = -x\,e^{-x^2/2}$$

$e^{-x^2/2} \gt 0$，所以正負號只看 $-x$：

在 $(-\infty, 0)$ 遞增、$(0, \infty)$ 遞減，$x = 0$ 有相對極大值 $f(0) = e^0 = 1$。

二階導數

前面 $-x$ 的微分是 $-1$；後面 $e^{-x^2/2}$ 的微分是 $-x\,e^{-x^2/2}$：

$$f''(x) = (-1)\,e^{-x^2/2} + (-x)(-x)\,e^{-x^2/2} = (x^2 - 1)\,e^{-x^2/2}$$

凹性與反曲點

$f''(x) = 0$ 的解是 $x^2 - 1 = 0$，也就是 $x = \pm 1$：

兩邊都變號，所以反曲點有兩個，高度是 $f(\pm 1) = e^{-1/2} \approx 0.607$。

圖形

在 $(-\infty, 0)$ 遞增、$(0, \infty)$ 遞減；相對極大值 $f(0) = 1$；反曲點 $\left(\pm 1,\ e^{-1/2}\right) \approx (\pm 1,\ 0.607)$。

這兩節最容易失分的地方：$e^{f(x)}$ 和 $\ln f(x)$ 忘了乘「裡面的微分」；把 $e^x$ 當成冪次規則；解 $f'(x) = 0$ 時白花時間去解 $e^{\cdots} = 0$（它沒有解，直接丟掉）。寫答案時，$\dfrac1e$、$\ln 8$ 這種精確值先留著，旁邊再補小數。
