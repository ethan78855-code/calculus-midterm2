第 4 章 · Section 4.1

一階導數：遞增遞減與相對極值

第 4 章開始用導數「看圖」。這一節只用一階導數 $f'$，回答兩個問題：函數在哪裡上升、哪裡下降？山頂和谷底在哪裡？整套做法就是微分、找分段點、畫符號圖，每一題都一樣。

遞增、遞減看 f′ 的正負號

由左往右看圖形：往上爬叫遞增，往下走叫遞減。暖身頁說過 $f'(x)$ 是切線斜率，斜率是正的線往右上走，所以：

在一個區間裡每一點都 $f'(x) \gt 0$：$f$ 在這個區間遞增
在一個區間裡每一點都 $f'(x) \lt 0$：$f$ 在這個區間遞減
在一個區間裡每一點都 $f'(x) = 0$：$f$ 在這個區間是常數（水平線）

所以「找遞增遞減區間」這件事，變成「找 $f'$ 在哪裡是正的、哪裡是負的」。

找遞增遞減區間的四步驟

$f'$ 要從正變成負，中間一定要經過 0，或是在某個點斷掉（不存在）。所以只要把這些點找出來，它們就把數線切成幾段，每一段裡面 $f'$ 的正負號不會變，挑一個點代進去就知道整段的符號。

  1. 先寫出 $f$ 的定義域（根號裡面要 $\ge 0$、分母不能是 0）。
  2. 求 $f'(x)$，盡量因式分解或通分成一個分式。
  3. 找出所有讓 $f'(x) = 0$ 或 $f'(x)$ 不存在的 $x$，標在數線上。
  4. 每一段挑一個測試點代入 $f'$，看正負，畫出符號圖，寫結論。

例 1：$f(x) = x^3 - 3x^2 - 24x + 32$（上面那張圖）。

$$f'(x) = 3x^2 - 6x - 24 = 3(x^2 - 2x - 8) = 3(x + 2)(x - 4)$$

$f'(x) = 0$ 的地方是 $x = -2$ 和 $x = 4$，數線被切成三段。每段挑一個好算的數字：

區間測試點$f'$ 的值符號結論
$(-\infty, -2)$$x = -3$$3(-1)(-7) = 21$＋遞增
$(-2, 4)$$x = 0$$3(2)(-4) = -24$－遞減
$(4, \infty)$$x = 5$$3(7)(1) = 21$＋遞增

把結果畫成符號圖。考試時畫這張圖就等於把過程交代清楚了：

結論：$f$ 在 $(-\infty, -2)$ 和 $(4, \infty)$ 遞增，在 $(-2, 4)$ 遞減。

例 2（有分母）：$f(x) = x + \dfrac1x$。定義域是 $x \ne 0$。

$$f'(x) = 1 - \frac{1}{x^2} = \frac{x^2 - 1}{x^2} = \frac{(x+1)(x-1)}{x^2}$$

$f'(x) = 0$ 在 $x = \pm 1$；$f'$ 在 $x = 0$ 不存在。三個點都要標，數線切成四段。分母 $x^2$ 永遠是正的，所以只要看分子 $(x+1)(x-1)$ 的正負：

分母等於 0、根號裡面小於 0 的地方，函數根本不存在。這些點雖然不是 $f' = 0$，畫符號圖時一樣要標上去，寫區間時也要把它們挖掉。

已知 $f'(x) = (x - 1)(x + 3)$。$f$ 在哪個區間遞減？

分段點是 $-3$ 和 $1$。中間挑 $x = 0$：$f'(0) = (-1)(3) = -3 \lt 0$，所以在 $(-3, 1)$ 遞減。兩邊各代一個點都是正的。

相對極大值與相對極小值

相對極大值是「山頂」：跟附近的點比，它最高。相對極小值是「谷底」：跟附近的點比，它最低。重點是「附近」，不必是整條曲線的最高或最低。

說法要精確：「$f$ 在 $x = 2$ 有相對極大值 $f(2) = \tfrac83$」。極值是 $y$ 的值，$x = 2$ 是它發生的位置。

看上圖，山頂和谷底的切線都是水平的，也就是 $f' = 0$。這給了我們找極值的線索。

臨界數：極值的候選名單

$c$ 是 $f$ 的臨界數，如果 $c$ 在 $f$ 的定義域裡，而且

$$f'(c) = 0 \qquad\text{或}\qquad f'(c) \text{ 不存在}$$

相對極值只會發生在臨界數。

但是反過來不一定：臨界數只是「候選人」，不保證真的有極值。下面兩張圖是兩種要小心的情況。

不在定義域裡的點不是臨界數。例如 $f(x) = x + \dfrac1x$，$f'(0)$ 不存在，但 $f(0)$ 本身就沒有定義，所以 $0$ 不是臨界數，那裡也不可能有極值。

$f(x) = \dfrac1x$，$f'(x) = -\dfrac{1}{x^2}$。$x = 0$ 是臨界數嗎？

臨界數的第一個條件是「在定義域裡」。$\dfrac10$ 沒有意義，所以 $0$ 不算。這個函數沒有任何臨界數。

一階導數檢定法

候選人找到了，怎麼確定它是山頂、谷底，還是都不是？看 $f'$ 在它左右兩邊的符號：

設 $c$ 是臨界數。由左到右經過 $c$ 時：

$f'$ 由 ＋ 變 －（先上後下）：$f(c)$ 是相對極大值
$f'$ 由 － 變 ＋（先下後上）：$f(c)$ 是相對極小值
$f'$ 沒有變號：$f(c)$ 不是相對極值

  1. 求 $f'$，找出所有臨界數（要在定義域裡）。
  2. 畫 $f'$ 的符號圖（不在定義域的分段點也要標）。
  3. 對每個臨界數看左右符號，判斷極大、極小、或都不是。
  4. 把臨界數代回原函數 $f$，算出極值。

例 1 續：$f(x) = x^3 - 3x^2 - 24x + 32$ 的符號圖是 ＋、－、＋。

  • $x = -2$：由＋變－，相對極大值 $f(-2) = -8 - 12 + 48 + 32 = 60$。
  • $x = 4$：由－變＋，相對極小值 $f(4) = 64 - 48 - 96 + 32 = -48$。

例 2 續：$f(x) = x + \dfrac1x$ 的符號圖是 ＋、－、－、＋。

  • $x = -1$：由＋變－，相對極大值 $f(-1) = -2$。
  • $x = 0$：不在定義域，不討論。
  • $x = 1$：由－變＋，相對極小值 $f(1) = 2$。

注意這裡相對極大值 $-2$ 比相對極小值 $2$ 還小。這不矛盾，因為「相對」只跟附近比。

例 3：上一段那條有兩座山的曲線，$f'(x) = -x^3 + x^2 + 2x = -x(x+1)(x-2)$：

$x = -1$（＋變－）相對極大，$x = 0$（－變＋）相對極小，$x = 2$（＋變－）相對極大，跟圖形一致。

某函數 $f$ 的符號圖顯示：$f'$ 在 $x = 2$ 的左邊是負的、右邊是正的，而且 $f(2) = 5$。下列何者正確？

先遞減再遞增，是谷底，所以是相對極小值。極值是函數值 $f(2) = 5$，位置是 $x = 2$。

$f(x) = x^3$，$f'(x) = 3x^2$，所以 $0$ 是臨界數。$f$ 在 $x = 0$ 有相對極值嗎？

$3x^2$ 除了 $x = 0$ 以外都是正的，符號圖是 ＋、＋。沒有變號就不是極值。$f' = 0$ 只是必要條件。

指定題

五題的前三題是「找區間、找極值」，後兩題是「證明一直遞減」。兩種都靠 $f'$ 的正負號。

根號函數的遞增遞減區間

求函數 $f(x) = \sqrt{16 - x^2}$ 的遞增區間與遞減區間。

提示

先找定義域：根號裡面 $16 - x^2 \ge 0$。微分用連鎖律，裡面 $16 - x^2$ 的微分是 $-2x$。

定義域

根號裡面不能是負的：$16 - x^2 \ge 0$，也就是 $x^2 \le 16$，所以 $-4 \le x \le 4$。這個函數只活在 $[-4, 4]$。

微分（連鎖律）

$$f(x) = (16 - x^2)^{1/2} \quad\Longrightarrow\quad f'(x) = \frac12(16 - x^2)^{-1/2}\cdot(-2x) = \frac{-x}{\sqrt{16 - x^2}}$$

找分段點

$f'(x) = 0$：分子 $-x = 0$，得 $x = 0$。

$f'(x)$ 不存在：分母 $\sqrt{16 - x^2} = 0$，得 $x = \pm 4$，剛好是定義域的兩個端點。

所以只需要看 $(-4, 0)$ 和 $(0, 4)$ 兩段。

判斷正負

在 $(-4, 4)$ 裡分母 $\sqrt{16 - x^2}$ 是正的，所以 $f'$ 的符號跟分子 $-x$ 一樣：

  • 測試點 $x = -2$：$f'(-2) = \dfrac{2}{\sqrt{12}} \gt 0$
  • 測試點 $x = 2$：$f'(2) = \dfrac{-2}{\sqrt{12}} \lt 0$

結論與圖形

把 $y = \sqrt{16 - x^2}$ 兩邊平方得 $x^2 + y^2 = 16$，圖形是半徑 4 的上半圓：左半邊往上爬，右半邊往下走。

$f$ 在 $(-4, 0)$ 遞增，在 $(0, 4)$ 遞減。

乘積函數的遞增遞減區間

求函數 $g(x) = x\sqrt{x + 1}$ 的遞增區間與遞減區間。

提示

定義域是 $x \ge -1$。用乘法規則微分後會有兩項，把它們通分成一個分式，才看得出哪裡等於 0。

定義域

根號裡面 $x + 1 \ge 0$，所以 $x \ge -1$，定義域是 $[-1, \infty)$。

微分（乘法規則）

前面是 $x$（微分是 1），後面是 $(x+1)^{1/2}$（微分是 $\dfrac{1}{2\sqrt{x+1}}$）：

$$g'(x) = 1\cdot\sqrt{x+1} + x\cdot\frac{1}{2\sqrt{x+1}}$$

通分

第一項上下同乘 $2\sqrt{x+1}$，分子變成 $2(x+1)$：

$$g'(x) = \frac{2(x+1) + x}{2\sqrt{x+1}} = \frac{3x + 2}{2\sqrt{x+1}}$$

找分段點

$g'(x) = 0$：分子 $3x + 2 = 0$，得 $x = -\dfrac23$。

$g'(x)$ 不存在：分母等於 0，得 $x = -1$，是定義域的端點。

所以看 $\left(-1, -\tfrac23\right)$ 和 $\left(-\tfrac23, \infty\right)$ 兩段。

判斷正負

$x \gt -1$ 時分母是正的，符號由分子 $3x + 2$ 決定：

  • 測試點 $x = -0.9$：$3(-0.9) + 2 = -0.7 \lt 0$
  • 測試點 $x = 0$：$3(0) + 2 = 2 \gt 0$

結論與圖形

$g$ 在 $\left(-1, -\tfrac23\right)$ 遞減，在 $\left(-\tfrac23, \infty\right)$ 遞增。

有分母的函數的相對極值

求函數 $g(x) = 2x^2 + \dfrac{4000}{x} + 10$ 的相對極大值與相對極小值（如果有的話）。

提示

$\dfrac{4000}{x} = 4000x^{-1}$。微分後通分，分子會出現 $x^3 - 1000$。別忘了 $x = 0$ 不在定義域，但符號圖上要標它。

定義域

分母不能是 0，所以定義域是 $x \ne 0$。

微分

$$g(x) = 2x^2 + 4000x^{-1} + 10 \quad\Longrightarrow\quad g'(x) = 4x - 4000x^{-2} = 4x - \frac{4000}{x^2}$$

通分並因式分解

$$g'(x) = \frac{4x^3 - 4000}{x^2} = \frac{4(x^3 - 1000)}{x^2}$$

找臨界數

$g'(x) = 0$：$x^3 = 1000$，得 $x = 10$。

$g'(x)$ 不存在：$x = 0$。但是 $0$ 不在定義域裡，所以它不是臨界數。唯一的臨界數是 $x = 10$。

畫符號圖

分段點是 $0$ 和 $10$（$0$ 雖然不是臨界數，還是會把數線切開）。分母 $x^2$ 永遠是正的，所以只看 $x^3 - 1000$：

  • $x = -1$：$(-1)^3 - 1000 \lt 0$
  • $x = 1$：$1 - 1000 \lt 0$
  • $x = 20$：$8000 - 1000 \gt 0$

一階導數檢定法

在 $x = 10$，$g'$ 由負變正，所以有相對極小值：

$$g(10) = 2(10)^2 + \frac{4000}{10} + 10 = 200 + 400 + 10 = 610$$

沒有任何地方是由正變負，所以沒有相對極大值。

相對極小值 $g(10) = 610$；沒有相對極大值。

證明平均成本一直在下降

某公司每週壓製 $x$ 片 CD 的平均成本（美元）為

$$\bar{C}(x) = -0.0001x + 2 + \frac{2000}{x} \qquad (0 \lt x \le 6000)$$

證明 $\bar{C}(x)$ 在區間 $(0, 6000)$ 上恆為遞減。

提示

「證明遞減」就是「證明導數在整個區間都是負的」。微分後不用解方程式，直接說明每一項的正負號。

微分

$$\bar{C}(x) = -0.0001x + 2 + 2000x^{-1} \quad\Longrightarrow\quad \bar{C}'(x) = -0.0001 - \frac{2000}{x^2}$$

說明導數恆為負

對 $(0, 6000)$ 裡的任何 $x$：

  • $x^2 \gt 0$，所以 $\dfrac{2000}{x^2} \gt 0$，也就是 $-\dfrac{2000}{x^2} \lt 0$。
  • $-0.0001 \lt 0$。

兩個負數相加還是負數，所以 $\bar{C}'(x) \lt 0$ 對所有 $0 \lt x \lt 6000$ 都成立。

結論

因為 $\bar{C}'(x) \lt 0$，$\bar{C}$ 在 $(0, 6000)$ 上恆為遞減。意思是：壓得越多，每一片平均攤到的成本越低。

$\bar{C}'(x) = -0.0001 - \dfrac{2000}{x^2} \lt 0$ 對所有 $0 \lt x \lt 6000$ 成立，所以 $\bar{C}$ 在 $(0, 6000)$ 恆遞減。

證明郵件量逐年下降

2008 年到 2012 年美國第一類郵件的投遞量（十億件）可以用下面的函數近似，其中 $t$ 的單位是年，$t = 0$ 代表 2008 年：

$$f(t) = \frac{90.7}{0.01t^2 + 0.01t + 1} \qquad (0 \le t \le 4)$$

證明在這段期間，第一類郵件的投遞量一直在下降。

提示

分子是常數，改寫成 $90.7\,(0.01t^2 + 0.01t + 1)^{-1}$ 用連鎖律最快。然後說明 $f'(t)$ 在 $(0, 4)$ 為什麼一定是負的。

微分（連鎖律）

外層是 $-1$ 次方，裡面 $0.01t^2 + 0.01t + 1$ 的微分是 $0.02t + 0.01$：

$$f'(t) = -90.7\,(0.01t^2 + 0.01t + 1)^{-2}\,(0.02t + 0.01) = \frac{-90.7\,(0.02t + 0.01)}{(0.01t^2 + 0.01t + 1)^2}$$

說明導數恆為負

對 $(0, 4)$ 裡的任何 $t$：

  • $t \gt 0$，所以 $0.02t + 0.01 \gt 0$。
  • 分母是平方，而且 $0.01t^2 + 0.01t + 1 \ge 1$ 不會是 0，所以分母 $\gt 0$。
  • 最前面有一個 $-90.7$。

負 × 正 ÷ 正 = 負，所以 $f'(t) \lt 0$ 對所有 $0 \lt t \lt 4$ 成立。

結論

$f'(t) \lt 0$，所以 $f$ 在 $(0, 4)$ 遞減：從 2008 年到 2012 年，第一類郵件的投遞量一直在下降（由 $f(0) = 90.7$ 降到 $f(4) \approx 75.6$）。

$f'(t) = \dfrac{-90.7(0.02t + 0.01)}{(0.01t^2 + 0.01t + 1)^2} \lt 0$ 對所有 $0 \lt t \lt 4$ 成立，所以投遞量在這段期間一直下降。

這一節的答題格式很固定，照著寫就不會漏分：寫出 $f'$ 並化成因式或單一分式、標出 $f' = 0$ 和 $f'$ 不存在的點、畫符號圖、用開區間寫出遞增遞減區間。極值要寫成「相對極小值 $g(10) = 610$」這種形式，記得代回原函數算，不是代回 $f'$。「證明遞增／遞減」的題目，一定要寫出「因為 $f' \lt 0$（或 $\gt 0$）對區間裡所有 $x$ 都成立」這句理由。
