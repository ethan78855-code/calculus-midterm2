最佳化 II：應用題

這一節有 8 題指定題，是這次考試份量最重的地方。好消息是：每一題的解法都是同一套五個步驟。微分本身很簡單，難的是把文字翻成一個函數。這一頁每一題都附一張可以拖曳的圖，先玩圖、再看算式。

這一節在做什麼

4.4 節的題目會直接給你函數，例如「求 $f(x) = x^3 - 3x$ 在 $[0, 2]$ 的最大值」。4.5 節的題目不給函數，只給一段故事：圍籬有多長、盒子容量多少、鳥飛多快，然後問「怎樣最大」或「怎樣最省」。

應用題 = 自己把函數寫出來 + 4.4 節學過的找最大最小。函數寫出來之後，剩下的就是微分、令它等於 0。

固定五步驟

  1. 畫圖、設變數。把題目畫出來，會變動的長度用 $x$、$y$ 標上去。
  2. 寫出目標。題目要最大或最小的那個量（面積、成本、時間……）用變數寫成式子。
  3. 用限制條件消掉一個變數。題目一定會給一個固定的數（圍籬總長、容量、周長），用它把 $y$ 換成 $x$，讓目標變成只有一個變數的函數 $f(x)$。
  4. 寫出 $x$ 的範圍。長度不能是負的，人數不能超過上限。
  5. 微分、令 $f'(x) = 0$ 找臨界數，並確認它真的是最大（或最小），最後回答題目問的東西，記得寫單位。

最常見的失分有兩種：第 3 步沒做，兩個變數就直接微分；第 5 步算出 $x$ 就停筆，忘了題目問的是「尺寸」「最大面積」還是「票價」。

暖身：用最簡單的題目走一遍

題目：周長 100 ft（英尺）的矩形，長和寬各是多少時面積最大？

先拖曳下面的圖。周長固定，矩形越扁面積越小；什麼形狀面積最大？

照五步驟寫：

  1. 設變數：長 $x$、寬 $y$（單位 ft）。
  2. 目標：面積 $A = xy$ 要最大。
  3. 限制條件：周長 $2x + 2y = 100$，所以 $y = 50 - x$。代進去： $$A(x) = x(50 - x) = 50x - x^2$$
  4. 範圍：長和寬都不能是負的，所以 $0 \le x \le 50$。
  5. 微分：$A'(x) = 50 - 2x = 0$，得 $x = 25$。比較 $A(0) = 0$、$A(25) = 625$、$A(50) = 0$，最大是 625。此時 $y = 50 - 25 = 25$。

長、寬都是 25 ft（正方形），最大面積 625 ft²。

怎麼確認是最大還是最小

$f'(x) = 0$ 只告訴你「那裡的切線是水平的」，山頂和谷底都是水平的。所以最後一定要確認。兩種方法擇一：

把臨界數和兩個端點都代進 $f$，比大小。最大的就是絕對極大值，最小的就是絕對極小值。這就是 4.4 節的做法。

看二階導數 $f''(x)$ 在整個範圍的正負：

$f''(x) \gt 0$（整條曲線凹向上，像碗）：那個臨界數是絕對極小。
$f''(x) \lt 0$（整條曲線凹向下，像山）：那個臨界數是絕對極大。

成本函數 $C(x)$ 的範圍是 $x \gt 0$，只有一個臨界數 $x = 3$，而且 $C''(x) = 80 + \dfrac{4320}{x^3}$。可以下什麼結論？

$x \gt 0$ 時 $C''(x)$ 一定是正的，整條曲線凹向上，唯一的臨界數就是絕對極小。範圍是開區間，沒有端點可以比。（這就是指定題 #9。）

有 3000 yd 的圍籬，沿著河岸圍一塊矩形（靠河那邊不用圍，中間也不加隔板）。垂直河岸的邊長設為 $x$、平行河岸的邊長設為 $y$，限制條件是？

垂直河岸的圍籬有左右兩道（$2x$），平行河岸的只有離河遠的那一道（$y$），靠河那邊不用圍。指定題 #4 中間多一道隔板，就會變成 $3x + y = 3000$。

遊艇 20 人報名時每人 600 美元。每多 1 人，所有人的票價都降 4 美元。多了 $x$ 人時，總收益是？

收益 = 人數 × 票價。人數變成 $20 + x$，每個人的票價變成 $600 - 4x$，兩個括號相乘。這種「多一個、單價就降一點」的題型（#20、#21）都是兩個括號相乘。

指定題

每一題的圖都可以拖曳。建議順序：先讀題目、拖一拖圖猜答案，自己照五步驟寫，卡住再一步一步打開解答。

沿河圍牧地，中間多一道隔板

牧場主人有 3000 yd（碼）的圍籬，要沿著一段筆直的河岸圍出一塊矩形牧地，靠河的那一側不用圍。他還要在中間加一道和兩側平行的圍籬，把牧地隔成兩塊。能圍出的最大面積是多少？此時牧地的尺寸是多少？

提示

數一數圖上有幾道長度是 $x$ 的圍籬。全部圍籬加起來是 3000，用這個條件把 $y$ 換成 $x$。

設變數、寫目標

垂直河岸的圍籬有三道（左、中、右），每道長 $x$ yd；平行河岸的圍籬一道，長 $y$ yd。要最大的是面積：

$$A = xy$$

用圍籬總長消掉 y

$$3x + y = 3000 \quad\Longrightarrow\quad y = 3000 - 3x$$ $$A(x) = x(3000 - 3x) = 3000x - 3x^2$$

注意是 $3x$ 不是 $2x$，因為中間多了一道隔板。

x 的範圍

$x \ge 0$，而且 $y = 3000 - 3x \ge 0$，所以 $0 \le x \le 1000$。

微分找臨界數

$$A'(x) = 3000 - 6x = 0 \quad\Longrightarrow\quad x = 500$$

確認是最大，回答問題

範圍是閉區間，比較臨界數和端點：

$x$05001000
$A(x)$0750,0000

最大值在 $x = 500$。此時 $y = 3000 - 3(500) = 1500$。（也可以用 $A''(x) = -6 \lt 0$ 確認。）

垂直河岸的邊長 500 yd、沿河的邊長 1500 yd，最大面積 750,000 yd²。

成本最低的筆筒

要做一個容量 36 in.³（立方英寸）的筆筒，形狀是正方形底、沒有蓋子的長方體。側面材料每平方英寸 15 美分，底部材料每平方英寸 40 美分。筆筒的尺寸要多少，材料成本才會最低？

提示

成本 = 底面積 × 40 + 四個側面的面積 × 15。沒有蓋子，所以不用算上面。容量 $x^2h = 36$ 用來把 $h$ 換掉。

設變數、寫目標

設底邊長 $x$ in.、高 $h$ in.。底是一個 $x \times x$ 的正方形，側面是四片 $x \times h$ 的長方形：

$$C = \underbrace{40\cdot x^2}_{\text{底}} + \underbrace{15\cdot 4xh}_{\text{四個側面}} = 40x^2 + 60xh \quad(\text{美分})$$

用容量消掉 h

$$x^2h = 36 \quad\Longrightarrow\quad h = \frac{36}{x^2}$$ $$C(x) = 40x^2 + 60x\cdot\frac{36}{x^2} = 40x^2 + \frac{2160}{x} \qquad (x \gt 0)$$

微分找臨界數

$\dfrac{2160}{x} = 2160x^{-1}$，微分是 $-2160x^{-2}$：

$$C'(x) = 80x - \frac{2160}{x^2} = 0 \quad\Longrightarrow\quad 80x^3 = 2160 \quad\Longrightarrow\quad x^3 = 27 \quad\Longrightarrow\quad x = 3$$

確認是最小

範圍 $x \gt 0$ 沒有端點，用二階導數：

$$C''(x) = 80 + \frac{4320}{x^3} \gt 0 \quad (x \gt 0)$$

曲線整段凹向上，唯一的臨界數 $x = 3$ 就是絕對極小。

回答問題

$$h = \frac{36}{3^2} = 4 \qquad C(3) = 40(9) + \frac{2160}{3} = 360 + 720 = 1080 \text{ 美分}$$

底 3 in. × 3 in.、高 4 in.（最低成本 1080 美分，也就是 10.80 美元）。

透光最多的諾曼窗

諾曼窗（Norman window）的形狀是一個矩形上面接一個半圓。如果窗框的周長是 28 ft，窗戶的尺寸要多少才能讓最多的光透進來（也就是面積最大）？課本的圖把半圓的半徑標成 $x$、矩形的高標成 $y$。

提示

周長是窗戶「外框」的長度：底邊 $2x$、左右兩邊各 $y$、上面的半圓弧 $\pi x$。矩形和半圓交界的那條線在窗戶裡面，不算周長。

設變數、寫目標

半圓半徑 $x$，所以矩形的寬是 $2x$；矩形的高是 $y$。面積 = 矩形 + 半圓：

$$A = 2xy + \tfrac12\pi x^2$$

用周長消掉 y

$$\underbrace{2x}_{\text{底}} + \underbrace{2y}_{\text{左右}} + \underbrace{\pi x}_{\text{半圓弧}} = 28 \quad\Longrightarrow\quad y = 14 - x - \frac{\pi x}{2}$$ $$\begin{aligned}A(x) &= 2x\left(14 - x - \frac{\pi x}{2}\right) + \frac{\pi x^2}{2}\\ &= 28x - 2x^2 - \pi x^2 + \frac{\pi x^2}{2}\\ &= 28x - 2x^2 - \frac{\pi x^2}{2}\end{aligned}$$

微分找臨界數

$\pi$ 只是一個數字（大約 3.14），當成常數處理：

$$A'(x) = 28 - 4x - \pi x = 28 - (4 + \pi)x = 0 \quad\Longrightarrow\quad x = \frac{28}{4 + \pi} \approx 3.92$$

確認是最大

$$A''(x) = -(4 + \pi) \lt 0$$

曲線整段凹向下，唯一的臨界數就是絕對極大。

算 y，回答問題

$$y = 14 - x\left(1 + \frac{\pi}{2}\right) = 14 - \frac{28}{4+\pi}\cdot\frac{2 + \pi}{2} = \frac{14(4 + \pi) - 14(2 + \pi)}{4 + \pi} = \frac{28}{4 + \pi} \approx 3.92$$

結果剛好 $y = x$：矩形的高等於半圓的半徑。考試時直接把 $x \approx 3.92$ 代進 $y = 14 - x - \dfrac{\pi x}{2}$ 按計算機也可以。

半圓半徑 $x = \dfrac{28}{4+\pi} \approx 3.92$ ft，矩形高 $y = \dfrac{28}{4+\pi} \approx 3.92$ ft（窗寬 $2x \approx 7.84$ ft），最大面積約 54.89 ft²。

蘋果園每英畝該種幾棵

蘋果園每英畝種 22 棵樹時，平均每棵可以收成 36 bushel（蒲式耳，容量單位）。每英畝每多種 1 棵，每棵樹的收成就少 2 蒲式耳。每英畝種幾棵，總收成最多？

提示

總收成 = 棵數 × 每棵收成。設每英畝「多種 $x$ 棵」，棵數是 $22 + x$，每棵收成是 $36 - 2x$。

設變數

設每英畝比 22 棵多種 $x$ 棵。那麼：

棵數 $= 22 + x$　　每棵收成 $= 36 - 2x$

寫目標函數

$$Y(x) = (22 + x)(36 - 2x) = 792 - 44x + 36x - 2x^2 = 792 - 8x - 2x^2$$

微分找臨界數

$$Y'(x) = -8 - 4x = 0 \quad\Longrightarrow\quad x = -2$$

解讀 x = −2，確認是最大

$Y''(x) = -4 \lt 0$，整段凹向下，所以 $x = -2$ 是絕對極大。

$x$ 是負的，意思是要比現在少種 2 棵：棵數 $22 - 2 = 20$，每棵收成 $36 - 2(-2) = 40$，總收成 $20 \times 40 = 800$ 蒲式耳，比原本的 $22 \times 36 = 792$ 多。

每英畝種 20 棵，總收成最多（800 蒲式耳）。

補充：如果規定只能多種

如果把題目讀成「只能增加棵數」（$x \ge 0$），那麼 $x \gt 0$ 時 $Y'(x) = -8 - 4x \lt 0$，收成一直遞減，最大就在端點 $x = 0$（維持 22 棵、792 蒲式耳）。這一題是雙數題，課本書末沒有附解答。題目問的是「種幾棵收成最多」，沒有說只能多種，所以這裡讓 $x$ 可以往兩邊變動，答案是 20 棵；考卷上把「$x = -2$ 代表少種 2 棵」這句話寫出來最保險。

遊艇出租的最大收益

一艘豪華遊艇，剛好 20 人報名時每人每天收 600 美元。超過 20 人時（最多可載 90 人），每多 1 人，每個人的票價都降 4 美元。假設至少有 20 人報名，幾個人報名時船東的收益最大？最大收益是多少？這時每個人的票價是多少？

提示

設超過 20 人的人數是 $x$。最多 90 人，所以 $x$ 最大是 70。這題範圍是閉區間，要比較端點。

設變數、寫範圍

設報名人數比 20 人多 $x$ 人。人數 $= 20 + x$，票價 $= 600 - 4x$。人數在 20 到 90 之間，所以 $0 \le x \le 70$。

寫目標函數

$$R(x) = (20 + x)(600 - 4x) = 12000 - 80x + 600x - 4x^2 = 12000 + 520x - 4x^2$$

微分找臨界數

$$R'(x) = 520 - 8x = 0 \quad\Longrightarrow\quad x = 65$$

$x = 65$ 在範圍 $[0, 70]$ 裡面，可以用。

比較臨界數和端點

$x$06570
人數 × 票價20 × 60085 × 34090 × 320
$R(x)$12,00028,90028,800

最大的是 $R(65) = 28{,}900$。人數 $20 + 65 = 85$，票價 $600 - 4(65) = 340$。

85 人報名時收益最大，每天 28,900 美元，此時每人票價 340 美元。

用料最省的穀倉

穀倉的形狀是一個直立的圓柱，上面蓋一個半球。穀倉的容量要 $504\pi$ ft³。半徑和圓柱的高各是多少，建造用的材料最少？

課本提示：體積是 $\pi r^2h + \tfrac23\pi r^3$，表面積（含地板）是 $\pi(3r^2 + 2rh)$。

提示

「用料最少」就是表面積最小。先把體積等式兩邊同除以 $\pi$，解出 $h$，再代進表面積公式。

設變數、寫目標

設半徑 $r$ ft、圓柱的高 $h$ ft。要最小的是表面積：

$$S = \underbrace{\pi r^2}_{\text{地板}} + \underbrace{2\pi rh}_{\text{圓柱側面}} + \underbrace{2\pi r^2}_{\text{半球}} = \pi(3r^2 + 2rh)$$

用容量消掉 h

$$\pi r^2h + \tfrac23\pi r^3 = 504\pi \quad\Longrightarrow\quad r^2h + \tfrac23 r^3 = 504 \quad\Longrightarrow\quad h = \frac{504}{r^2} - \frac{2r}{3}$$ $$S(r) = \pi\left[3r^2 + 2r\left(\frac{504}{r^2} - \frac{2r}{3}\right)\right] = \pi\left[3r^2 + \frac{1008}{r} - \frac{4r^2}{3}\right] = \pi\left(\frac{5r^2}{3} + \frac{1008}{r}\right)$$

$3r^2 - \tfrac43 r^2 = \tfrac53 r^2$。範圍是 $r \gt 0$。

微分找臨界數

$$S'(r) = \pi\left(\frac{10r}{3} - \frac{1008}{r^2}\right) = 0 \quad\Longrightarrow\quad \frac{10r}{3} = \frac{1008}{r^2} \quad\Longrightarrow\quad r^3 = \frac{3024}{10} = 302.4$$ $$r = \sqrt[3]{302.4} \approx 6.71$$

計算機按法：302.4 的 $(1 \div 3)$ 次方，或用立方根鍵。

確認是最小

$$S''(r) = \pi\left(\frac{10}{3} + \frac{2016}{r^3}\right) \gt 0 \quad (r \gt 0)$$

整段凹向上，唯一的臨界數是絕對極小。

算 h，回答問題

$$h = \frac{504}{r^2} - \frac{2r}{3} \approx \frac{504}{45.05} - 4.475 \approx 11.187 - 4.475 \approx 6.71$$

剛好 $h = r$。（原因：$\dfrac{504}{r^2} = \dfrac{504\,r}{r^3} = \dfrac{504\,r}{302.4} = \dfrac53 r$，所以 $h = \tfrac53 r - \tfrac23 r = r$。）

半徑 $r = \sqrt[3]{302.4} \approx 6.71$ ft，圓柱高 $h \approx 6.71$ ft。

鳥該從哪裡上岸最省時間

有些鳥在水面上飛得比在陸地上慢。一隻鳥在水面上的速度是 4 mph（每小時英里），在陸地上是 6 mph。牠從島上的 $E$ 點出發，島離筆直的海岸 3 mi（英里）；鳥巢 $N$ 在海岸上，離「島正對岸的那一點」12 mi。鳥先直線飛過水面到岸上的 $P$ 點，再沿著海岸飛到 $N$。$P$ 點離正對岸那一點 $x$ mi，$x$ 是多少時總時間最短？

提示

時間 = 距離 ÷ 速度，水上和陸上分開算再相加。水上那一段是直角三角形的斜邊，兩股是 3 和 $x$。

把兩段距離寫出來

水上：$E$ 到 $P$ 是直角三角形的斜邊，兩股是 3 和 $x$，距離 $\sqrt{x^2 + 9}$。
陸上：$P$ 到 $N$ 的距離是 $12 - x$。

寫目標函數（總時間）

$$T(x) = \underbrace{\frac{\sqrt{x^2 + 9}}{4}}_{\text{水上，4 mph}} + \underbrace{\frac{12 - x}{6}}_{\text{陸上，6 mph}} \qquad (0 \le x \le 12)$$

微分

$\sqrt{x^2+9} = (x^2+9)^{1/2}$ 用連鎖律，裡面的微分是 $2x$：

$$T'(x) = \frac14\cdot\frac12(x^2+9)^{-1/2}\cdot 2x - \frac16 = \frac{x}{4\sqrt{x^2+9}} - \frac16$$

令 T′(x) = 0 解 x

$$\frac{x}{4\sqrt{x^2+9}} = \frac16 \quad\Longrightarrow\quad 6x = 4\sqrt{x^2+9} \quad\Longrightarrow\quad 3x = 2\sqrt{x^2+9}$$

根號已經單獨在一邊，兩邊平方：

$$9x^2 = 4(x^2 + 9) \quad\Longrightarrow\quad 5x^2 = 36 \quad\Longrightarrow\quad x = \frac{6}{\sqrt5} \approx 2.68$$

$x$ 是距離，只取正的。

比較臨界數和端點

$x$02.6812
$T(x)$（小時）2.7502.5593.092

$T(0) = \tfrac34 + 2$，$T(12) = \tfrac{\sqrt{153}}{4}$。最小的是 $x \approx 2.68$。

$P$ 點選在離正對岸那一點 $x = \dfrac{6}{\sqrt5} \approx 2.68$ mi 的地方（往鳥巢的方向），總時間最短，約 2.56 小時。

划船加走路，怎麼走最快

一位女士在湖上的小船裡，離筆直湖岸上最近的 $P$ 點 1 mi。她要去岸上的 $Q$ 點，$Q$ 沿著湖岸離 $P$ 有 10 mi。她打算先划船到 $P$、$Q$ 之間的某一點 $R$，再走路到 $Q$。划船速度 3 mph，走路速度 4 mph。$R$ 要選在哪裡才能最快到 $Q$？需要多少時間？

提示

和 #29 完全同一型。設 $P$ 到 $R$ 的距離是 $x$，划船距離是斜邊 $\sqrt{1 + x^2}$，走路距離是 $10 - x$。

設變數、寫目標函數

設 $P$ 到 $R$ 的距離是 $x$ mi（$0 \le x \le 10$）。划船距離是直角三角形的斜邊 $\sqrt{1 + x^2}$，走路距離是 $10 - x$：

$$T(x) = \underbrace{\frac{\sqrt{1 + x^2}}{3}}_{\text{划船，3 mph}} + \underbrace{\frac{10 - x}{4}}_{\text{走路，4 mph}}$$

微分

$$T'(x) = \frac13\cdot\frac12(1 + x^2)^{-1/2}\cdot 2x - \frac14 = \frac{x}{3\sqrt{1+x^2}} - \frac14$$

令 T′(x) = 0 解 x

$$\frac{x}{3\sqrt{1+x^2}} = \frac14 \quad\Longrightarrow\quad 4x = 3\sqrt{1 + x^2}$$

兩邊平方：

$$16x^2 = 9(1 + x^2) \quad\Longrightarrow\quad 7x^2 = 9 \quad\Longrightarrow\quad x = \frac{3}{\sqrt7} \approx 1.13$$

比較臨界數和端點

$x$01.1310
$T(x)$（小時）2.8332.7203.350

$T(0) = \tfrac13 + \tfrac{10}{4}$，$T(10) = \tfrac{\sqrt{101}}{3}$。最小的是 $x \approx 1.13$。

算最短時間，回答問題

把 $x = \dfrac{3}{\sqrt7}$ 代回去：$\sqrt{1 + x^2} = \sqrt{\tfrac{16}{7}} = \dfrac{4}{\sqrt7}$，所以

$$T = \frac{4}{3\sqrt7} + \frac{10}{4} - \frac{3}{4\sqrt7} = 2.5 + \frac{\sqrt7}{12} \approx 2.72 \text{ 小時}$$

$R$ 選在離 $P$ 點 $x = \dfrac{3}{\sqrt7} \approx 1.13$ mi 的地方，最短時間約 2.72 小時（大約 2 小時 43 分）。

應用題是照步驟給分的。就算最後算錯，只要寫出「設 $x$ 是什麼」「目標函數」「限制條件」「$f'(x) = 0$」這幾行，都拿得到部分分數。算出臨界數後一定要補一句確認（比較端點，或 $f'' \gt 0$／$f'' \lt 0$），最後用一句話回答題目問的東西並寫單位。這節會用到 $\pi$、根號和立方根，記得帶計算機，中間過程不要太早四捨五入。
