暖身 · 考試範圍的地基

微分從零開始

這次考的 3.4 到第 5 章，每一題都要先「微分」。這一頁不在考試範圍裡，但是不會這一頁，後面全部看不懂。花 20 分鐘把它弄熟，後面會快很多。

先從直線的斜率開始

斜率就是「往右走 1 步，高度變多少」。往右走了 $\Delta x$，高度變了 $\Delta y$，斜率就是兩個相除：

$$\text{斜率} = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}$$

斜率是正的，線往右上走；斜率是負的，線往右下走；斜率是 0，線是水平的。這三句話之後會一直用到。

曲線每一點的斜率都不一樣

曲線彎來彎去，沒辦法只用一個數字描述它的陡峭程度。做法是：想知道曲線在某一點有多陡，就看那一點的切線（剛好貼著曲線的那條直線）的斜率。

切線斜率怎麼算？先在曲線上取兩個點 $P$、$Q$ 連成一條割線，然後讓 $Q$ 一直靠近 $P$。拉動下面的滑桿試試看：

用式子寫，$P$ 在 $x$，$Q$ 在 $x+h$，割線斜率是 $\dfrac{f(x+h)-f(x)}{h}$。讓 $h$ 趨近 0，就得到導數：

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

導數 $f'(x)$ 就是「曲線在 $x$ 這一點的切線斜率」。求導數這個動作叫做微分。考試不會要你用極限慢慢算，直接套下面的規則就好。

在上圖把 x 拖到 0，切線斜率是 −3。這代表什麼？

導數是斜率，不是高度。斜率是負的就代表正在下降；有極值的地方斜率要是 0。

記號：同一件事有三種寫法

如果 $y = f(x)$，下面三個寫法意思完全一樣，都是「把 $y$ 對 $x$ 微分」：

$$f'(x) \qquad \frac{dy}{dx} \qquad \frac{d}{dx}\big[f(x)\big]$$

課本三種都會出現。$\dfrac{dy}{dx}$ 不是分數，把它整個當成一個符號看就好。

四條基本規則

先把這張表記起來，絕大多數多項式都只需要這四條：

規則公式例子
常數$\dfrac{d}{dx}(c) = 0$$(7)' = 0$
冪次$\dfrac{d}{dx}(x^n) = n\,x^{n-1}$$(x^5)' = 5x^4$
常數倍$\dfrac{d}{dx}\big[c\,f(x)\big] = c\,f'(x)$$(4x^3)' = 12x^2$
加減$\dfrac{d}{dx}\big[f \pm g\big] = f' \pm g'$$(x^2 + 3x)' = 2x + 3$

冪次規則的口訣：次方搬下來乘，次方再減 1。$x$ 本身是 $x^1$，所以 $(x)' = 1$；常數沒有 $x$，微分是 0。

例：$f(x) = 2x^3 - 5x^2 + 4x - 9$

$$f'(x) = 2\cdot 3x^2 - 5\cdot 2x + 4 - 0 = 6x^2 - 10x + 4$$

根號和分數，先改寫成次方再微分

這是最常卡住的地方。看到根號或 $x$ 在分母，第一步一定是改寫：

$$\sqrt{x} = x^{1/2} \qquad \frac{1}{x} = x^{-1} \qquad \frac{1}{x^2} = x^{-2} \qquad \frac{1}{\sqrt{x}} = x^{-1/2}$$

改寫完一樣用冪次規則：

$$\frac{d}{dx}\sqrt{x} = \tfrac12 x^{-1/2} = \frac{1}{2\sqrt{x}} \qquad\qquad \frac{d}{dx}\Big(\frac{1}{x}\Big) = -x^{-2} = -\frac{1}{x^2}$$

例（這次指定題會用到）：$g(x) = 2x^2 + \dfrac{4000}{x} + 10 = 2x^2 + 4000x^{-1} + 10$

$$g'(x) = 4x - 4000x^{-2} = 4x - \frac{4000}{x^2}$$

$f(x) = 3x^4 - \dfrac{6}{x}$，$f'(x)$ 是？

$-\dfrac{6}{x} = -6x^{-1}$，微分是 $-6\cdot(-1)x^{-2} = +\dfrac{6}{x^2}$。負負得正，這個正負號很容易錯。

兩個函數相乘、相除

$$\big[f(x)\,g(x)\big]' = f'(x)\,g(x) + f(x)\,g'(x)$$

口訣：前微後不微，加上前不微後微。

例：$y = x\sqrt{x+1}$（這是指定題 4.1 #35 的函數）。前面是 $x$，後面是 $(x+1)^{1/2}$：

$$y' = \underbrace{1}_{\text{前微}}\cdot\sqrt{x+1} + x\cdot\underbrace{\frac{1}{2\sqrt{x+1}}}_{\text{後微}}$$
$$\left[\frac{f(x)}{g(x)}\right]' = \frac{f'(x)\,g(x) - f(x)\,g'(x)}{\big[g(x)\big]^2}$$

口訣：分母平方當分母；分子是「上微下不微，減上不微下微」。

例：$y = \dfrac{2x}{x^2+1}$（指定題 4.2 #70）。上面 $f = 2x$，$f' = 2$；下面 $g = x^2+1$，$g' = 2x$：

$$y' = \frac{2(x^2+1) - 2x\cdot 2x}{(x^2+1)^2} = \frac{2 - 2x^2}{(x^2+1)^2}$$

$(fg)' \ne f'g'$，$\left(\dfrac{f}{g}\right)' \ne \dfrac{f'}{g'}$。乘除不能各自微分。另外除法規則分子是減號，而且順序不能顛倒（先微上面）。

連鎖律：一層包一層的函數

像 $(2x+1)^5$、$\sqrt{16 - x^2}$ 這種「裡面還有一包東西」的函數，要用連鎖律。

$$\frac{d}{dx}\big[g(x)\big]^n = n\,\big[g(x)\big]^{n-1}\cdot g'(x)$$

口訣：外面照微、裡面不動，再乘上裡面的微分。

  1. 把裡面那包東西當成一個整體（先用手遮住它）。
  2. 對外層微分，裡面那包原封不動抄下來。
  3. 再乘上「裡面那包」自己的微分。

例 1：$y = (2x+1)^5$。外層是 5 次方，裡面是 $2x+1$（微分是 2）：

$$y' = 5(2x+1)^4 \cdot 2 = 10(2x+1)^4$$

例 2：$y = \sqrt{16 - x^2} = (16 - x^2)^{1/2}$（指定題 4.1 #34）。裡面是 $16 - x^2$（微分是 $-2x$）：

$$y' = \tfrac12 (16 - x^2)^{-1/2}\cdot(-2x) = \frac{-x}{\sqrt{16 - x^2}}$$

例 3：$y = \dfrac{90.7}{0.01t^2 + 0.01t + 1} = 90.7\,(0.01t^2 + 0.01t + 1)^{-1}$（指定題 4.1 #89）。分子是常數時，改寫成 $-1$ 次方用連鎖律比除法規則快：

$$y' = -90.7\,(0.01t^2 + 0.01t + 1)^{-2}\cdot(0.02t + 0.01)$$

最常見的失分：忘記乘「裡面的微分」。$\big[(2x+1)^5\big]'$ 寫成 $5(2x+1)^4$ 就少了後面的 $\times 2$。

$y = (x^2 + 3)^4$，$\dfrac{dy}{dx}$ 是？

外層：$4(x^2+3)^3$。裡面 $x^2+3$ 的微分是 $2x$。相乘得到 $8x(x^2+3)^3$。

$y = \sqrt{3x + 1}$，$y'$ 是？

$(3x+1)^{1/2}$ 微分：$\tfrac12(3x+1)^{-1/2}\times 3$。裡面 $3x+1$ 的微分是 3，要乘上去。

過關檢查

下面每一題都能在 30 秒內寫出來，就可以進 3.4 了。先自己算，再點開看答案。

$f(x) = 0.000002x^3 - 0.03x^2 + 400x + 80000$，求 $f'(x)$

$f'(x) = 0.000006x^2 - 0.06x + 400$。小數看起來可怕，規則完全一樣：次方搬下來乘、次方減 1。這是 3.4 #13 的成本函數。

$f(x) = \dfrac{80000}{x}$，求 $f'(x)$

$80000x^{-1}$ 微分得 $-80000x^{-2} = -\dfrac{80000}{x^2}$。

$g(t) = \left(\tfrac12 t^2 - 1\right)^5$，求 $g'(t)$

連鎖律：$5\left(\tfrac12 t^2 - 1\right)^4\cdot t = 5t\left(\tfrac12 t^2 - 1\right)^4$。裡面 $\tfrac12 t^2 - 1$ 的微分是 $t$。這是 3.5 #28 的第一步。

$f(x) = \dfrac{x^2 - 9}{x^2 - 4}$，求 $f'(x)$

除法規則：$\dfrac{2x(x^2-4) - (x^2-9)(2x)}{(x^2-4)^2} = \dfrac{10x}{(x^2-4)^2}$。這是 4.3 #56 會用到的。
