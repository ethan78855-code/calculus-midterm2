老師提示的六題

老師提示的題目是 3.6 的 #34、#44、#49，4.3 的 #56，4.5 的 #21，5.6 的 #27，數起來是六題。這一頁把六題從最基礎講起：每一題先補齊它需要的觀念，再一步一步算，最後給「考卷上可以照著寫的版本」和一題換數字的練習。六題讀熟之後，再回頭看其他章節。

怎麼讀這一頁

六題照「由淺到深」排，不是照章節排。前三題是同一招（隱函數微分），一起讀最省力。

工具箱：微分規則

導數 $f'(x)$ 是圖形在那一點的切線斜率，也可以讀成「$x$ 多一點點時，$f$ 跟著變多少」。$f'(x)$、$y'$、$\dfrac{dy}{dx}$ 是同一個東西的三種寫法。

六題裡要微分的地方，只會用到下面這幾條規則：

規則公式例子哪一題用到
常數$(c)' = 0$$(72)' = 0$全部
冪次規則$(x^n)' = n\,x^{n-1}$$(x^3)' = 3x^2$，$(x)' = 1$全部
常數倍、加減一項一項微$(520x - 4x^2)' = 520 - 8x$④
連鎖律$\big[(\text{一包})^n\big]' = n(\text{一包})^{n-1}\cdot(\text{一包})'$$\big[(2x+1)^3\big]' = 3(2x+1)^2\cdot 2$①②③⑥
乘法規則$(fg)' = f'g + fg'$$\big[x^2(x+1)\big]' = 2x(x+1) + x^2\cdot 1$②
除法規則$\Big(\dfrac{f}{g}\Big)' = \dfrac{f'g - fg'}{g^2}$$\Big(\dfrac{x}{x+1}\Big)' = \dfrac{1\cdot(x+1) - x\cdot 1}{(x+1)^2}$⑤
$e$ 的次方$(e^{kt})' = k\,e^{kt}$$(e^{-0.4t})' = -0.4\,e^{-0.4t}$⑥

連鎖律是這六題的主角。口訣：外面照微，裡面那一包先不動，最後再乘上「那一包自己的微分」。前三題的「看到 $y$ 就多乘 $\dfrac{dy}{dx}$」其實就是連鎖律，因為 $y$ 也是一包 $x$ 的函數。

$\big[(3x - 1)^4\big]'$ 是？

外面是 4 次方：$4(3x-1)^3$。裡面那包 $3x - 1$ 的微分是 3，要乘上去：$4\cdot 3 = 12$。第一個選項忘了乘裡面的微分。

$\big(x^{3/5}\big)'$ 是？

分數次方一樣用冪次規則：次方 $\tfrac35$ 搬下來乘，次方再減 1：$\tfrac35 - 1 = -\tfrac25$。

規則還不熟的話，暖身頁有每一條規則的慢動作版。

① 3.6 #34 隱函數的切線

題目給一條 $x$、$y$ 混在一起的方程式，和圖形上的一個點，要你寫出那一點的切線。只要做兩件事：用隱函數微分算出斜率，再用點斜式寫出直線。

先補觀念 1：寫一條直線，只需要「一個點」和「斜率」

$$y - y_0 = m\,(x - x_0)$$

$(x_0, y_0)$ 是直線通過的點，$m$ 是斜率。

例：通過 $(2, 5)$、斜率 3 的直線是 $y - 5 = 3(x - 2)$，整理後是 $y = 3x - 1$。

這一題的點已經給了，是 $(1, -1)$。缺的只有斜率，而切線斜率就是 $\dfrac{dy}{dx}$ 在那一點的值。

先補觀念 2：y 沒有單獨在一邊，照樣可以微分

平常的題目長得像 $y = x^2 + 1$，$y$ 自己在一邊。這題是 $(x - y - 1)^3 = x$，$y$ 被包在括號裡。這種叫隱函數：$y$ 還是跟著 $x$ 變，只是沒有寫成「$y = \cdots$」。

做法是不去解 $y$，直接把等號兩邊同時對 $x$ 微分。微分時記住三句話：

看到 $x$，微分是 $1$。
看到 $y$，微分是 $\dfrac{dy}{dx}$（因為 $y$ 是 $x$ 的函數，它怎麼變我們還不知道，先用這個符號代表）。
看到常數，微分是 $0$。

最簡單的例子：$x^2 + y^2 = 25$。$x^2$ 微分是 $2x$；$y^2$ 是「一包 $y$ 的平方」，照連鎖律是 $2y$ 再乘 $y$ 自己的微分：

$$2x + 2y\,\frac{dy}{dx} = 0 \quad\Longrightarrow\quad \frac{dy}{dx} = -\frac{x}{y}$$

先補觀念 3：一整包的三次方怎麼微

左邊 $(x - y - 1)^3$ 是「一包東西的 3 次方」。連鎖律：

$$\big[(\text{一包})^3\big]' = 3(\text{一包})^2\cdot(\text{一包})'$$

這一包是 $x - y - 1$，一項一項微：

包裡的項$x$$-y$$-1$
它的微分$1$$-\dfrac{dy}{dx}$$0$

所以這一包的微分是 $1 - \dfrac{dy}{dx}$。下面的解答就是把這三個觀念接起來。

求隱函數圖形在指定點的切線

求方程式 $(x - y - 1)^3 = x$ 的圖形在點 $(1, -1)$ 的切線方程式。

提示

兩邊對 $x$ 微分。左邊用連鎖律，裡面那包的微分是 $1 - \dfrac{dy}{dx}$。微分完再把 $x = 1$、$y = -1$ 代進去，就能解出斜率。

先確認點在圖形上

把 $x = 1$、$y = -1$ 代進方程式：左邊 $(1 - (-1) - 1)^3 = 1^3 = 1$，右邊 $x = 1$，相等。

這一步考卷上可以不寫，但花五秒檢查，可以抓到題目抄錯或正負號看錯。

兩邊對 x 微分

左邊：外面 3 次方照微，得 $3(x - y - 1)^2$，再乘裡面那包的微分 $1 - \dfrac{dy}{dx}$。
右邊：$x$ 的微分是 $1$。

$$3(x - y - 1)^2\Big(1 - \frac{dy}{dx}\Big) = 1$$

把點代進去

已經微分完了，現在可以代數字。在 $(1, -1)$，括號裡 $x - y - 1 = 1 + 1 - 1 = 1$：

$$3(1)^2\Big(1 - \frac{dy}{dx}\Big) = 1 \quad\Longrightarrow\quad 3\Big(1 - \frac{dy}{dx}\Big) = 1$$

解出斜率

$$1 - \frac{dy}{dx} = \frac13 \quad\Longrightarrow\quad \frac{dy}{dx} = 1 - \frac13 = \frac23$$

切線斜率是 $\dfrac23$。

如果題目沒有給點、只要求 $\dfrac{dy}{dx}$，就把上一步的式子解到底：$\dfrac{dy}{dx} = 1 - \dfrac{1}{3(x - y - 1)^2}$。

用點斜式寫出切線

點 $(1, -1)$、斜率 $\dfrac23$。注意 $y_0 = -1$，所以 $y - (-1)$ 會變成 $y + 1$：

$$y + 1 = \frac23\,(x - 1) \quad\Longrightarrow\quad y = \frac23x - \frac23 - 1 = \frac23x - \frac53$$

看圖驗算

這條方程式其實解得出 $y$：兩邊開立方得 $x - y - 1 = \sqrt[3]{x}$，所以 $y = x - 1 - \sqrt[3]{x}$。下面的圖就是用它畫的。拖曳看看：「公式算的斜率」和「圖上量到的斜率」永遠一樣，在 $x = 1$ 都是 $0.667$。

$y = \dfrac23x - \dfrac53$（寫成 $2x - 3y - 5 = 0$ 也可以）

  • 包裡 $-y$ 的微分是 $-\dfrac{dy}{dx}$。負號最容易掉，掉了斜率會算成 $-\dfrac23$。
  • 只寫 $3(x-y-1)^2 = 1$，忘了乘「裡面那包的微分」。
  • 把 $-1$ 的微分寫成 $-1$。常數的微分是 $0$。
  • 還沒微分就把 $x = 1$、$y = -1$ 代進去。那樣兩邊都變成數字，沒有東西可以微了。先微分，再代點。
  • 點斜式寫成 $y - 1$。$y_0$ 是 $-1$，要寫 $y + 1$。

兩邊對 $x$ 微分：$3(x - y - 1)^2\,(1 - y') = 1$

代入 $(1, -1)$：$3(1)^2(1 - y') = 1$，所以 $y' = \dfrac23$

切線：$y + 1 = \dfrac23(x - 1)$，即 $y = \dfrac23x - \dfrac53$

換個數字練一次：求 $x^2 + y^3 = 9$ 在點 $(1, 2)$ 的切線

兩邊對 $x$ 微分：$2x + 3y^2\,\dfrac{dy}{dx} = 0$。

代入 $(1, 2)$：$2 + 12\,\dfrac{dy}{dx} = 0$，所以 $\dfrac{dy}{dx} = -\dfrac16$。

切線：$y - 2 = -\dfrac16(x - 1)$，即 $y = -\dfrac16x + \dfrac{13}{6}$。

② 3.6 #49 產出與 MRTS

一個國家的產出 $Q$ 由兩種花費決定：花在勞動的 $x$、花在資本的 $y$。(a) 小題只是把數字代進去。(b) 小題問：產出要維持不變，勞動多花一點，資本可以少花多少？這就是求 $\dfrac{dy}{dx}$，方法和上一題一樣是隱函數微分。

先補觀念 1：分數次方怎麼算

$x^{3/5}$ 的分母 5 代表「開 5 次方根」，分子 3 代表「3 次方」：$x^{3/5} = \big(\sqrt[5]{x}\,\big)^3$。先開根號，數字會變小，比較好算。

要算的先認出它是誰的 5 次方開 5 次方根再做分子的次方
$32^{3/5}$$32 = 2^5$$2$$2^3 = 8$
$243^{2/5}$$243 = 3^5$$3$$3^2 = 9$

課本這種題目的數字都是湊好的（$2^5 = 32$、$3^5 = 243$）。看不出來也沒關係，計算機按 32 ^ ( 3 ÷ 5 ) = 會得到 8。次方的括號一定要加，不加會變成 $32^3 \div 5$。

分數次方的微分照樣用冪次規則：$\big(x^{3/5}\big)' = \tfrac35x^{-2/5}$，$\big(y^{2/5}\big)' = \tfrac25y^{-3/5}$（之後還要乘 $\dfrac{dy}{dx}$）。

先補觀念 2：「產出維持不變」是一條 x 和 y 的關係式

(a) 會算出產出是 1440。「維持在這個水準」的意思是 $Q$ 不准變，永遠等於 1440：

$$20x^{3/5}y^{2/5} = 1440$$

勞動 $x$ 多花一點，資本 $y$ 就可以少花一點，產出還是一樣。所以 $y$ 會跟著 $x$ 變，只是沒寫成「$y = \cdots$」。這就是隱函數。下圖畫出所有「產出剛好 1440」的 $(x, y)$：

先補觀念 3：dy/dx 就是「x 多 1，y 大約變多少」

3.4 節的「邊際」就是這個想法：導數可以當成「再多 1 單位時的變化量」。這裡 $\dfrac{dy}{dx}$ 算出來大約是 $-11.4$，意思是勞動多花 1（十億美元），資本大約要少 11.4（十億美元）。

$$\text{MRTS} = -\frac{dy}{dx}$$

把 $\dfrac{dy}{dx}$ 的負號拿掉，寫成正數。它回答「多 1 單位勞動，可以換掉多少資本」。

產出函數：算產出，再求資本該怎麼調整

某國的產出為 $Q = 20x^{3/5}y^{2/5}$，其中 $x$ 是花在勞動上的金額，$y$ 是花在資本上的金額，三個量的單位都是十億美元。

(a) 勞動花 32、資本花 243（十億美元）時，產出是多少？
(b) 如果產出要維持在 (a) 的水準，勞動支出增加 1（十億美元）時，資本支出應該改變多少？MRTS 是多少？

提示

(a) $32 = 2^5$，$243 = 3^5$。(b) 把「產出不變」寫成 $20x^{3/5}y^{2/5} = 1440$，兩邊對 $x$ 微分。左邊是 $x^{3/5}$ 和 $y^{2/5}$ 相乘，要用乘法規則，$y$ 那一塊微分後要多乘 $\dfrac{dy}{dx}$。

(a) 把數字代進去

$$Q = 20\cdot 32^{3/5}\cdot 243^{2/5} = 20\cdot 8\cdot 9 = 1440$$

產出是 1440（十億美元）。

(b) 把「產出不變」寫成方程式

$$20x^{3/5}y^{2/5} = 1440 \quad\Longrightarrow\quad x^{3/5}y^{2/5} = 72$$

兩邊先除以 20，後面比較好算。右邊是常數，微分會是 0。

兩邊對 x 微分（乘法規則）

左邊是兩塊相乘：前面 $x^{3/5}$，後面 $y^{2/5}$。

前面的微分：$\tfrac35x^{-2/5}$。
後面的微分：$\tfrac25y^{-3/5}\cdot\dfrac{dy}{dx}$（$y$ 是 $x$ 的函數，要多乘 $\dfrac{dy}{dx}$）。

$$\underbrace{\tfrac35x^{-2/5}}_{\text{前微}}\cdot y^{2/5} + x^{3/5}\cdot\underbrace{\tfrac25y^{-3/5}\,\frac{dy}{dx}}_{\text{後微}} = 0$$

解出 dy/dx

把沒有 $\dfrac{dy}{dx}$ 的那一項移到右邊，再除過去：

$$\tfrac25x^{3/5}y^{-3/5}\,\frac{dy}{dx} = -\tfrac35x^{-2/5}y^{2/5} \quad\Longrightarrow\quad \frac{dy}{dx} = -\frac{\tfrac35\,x^{-2/5}\,y^{2/5}}{\tfrac25\,x^{3/5}\,y^{-3/5}}$$

分成數字、$x$、$y$ 三塊各自化簡（同底相除，次方相減）：

哪一塊算式結果
數字$\tfrac35 \div \tfrac25$$\tfrac32$
$x$$x^{-2/5} \div x^{3/5} = x^{-2/5 - 3/5}$$x^{-1} = \dfrac1x$
$y$$y^{2/5} \div y^{-3/5} = y^{2/5 + 3/5}$$y$
$$\frac{dy}{dx} = -\frac32\cdot\frac{y}{x}$$

代入 x = 32、y = 243

$$\frac{dy}{dx} = -\frac32\cdot\frac{243}{32} = -\frac{729}{64} \approx -11.39$$

不想化簡的話，也可以把數字直接代進微分完的那一行：$32^{-2/5} = \tfrac14$、$243^{2/5} = 9$、$32^{3/5} = 8$、$243^{-3/5} = \tfrac{1}{27}$，得到 $\tfrac{27}{20} + \tfrac{16}{135}\dfrac{dy}{dx} = 0$，解出來一樣是 $-11.39$。

解讀，回答兩個問題

$\dfrac{dy}{dx} \approx -11.39$ 是負的：勞動多花 1，資本要減少大約 11.4，產出才會維持在 1440。

MRTS 是 $-\dfrac{dy}{dx}$，寫成正數：大約 11.4。

(a) 1440（十億美元）。(b) 資本支出應減少約 11.4（十億美元）；MRTS $= \dfrac{729}{64} \approx 11.4$，也就是每多花 1（十億美元）在勞動上，可以少花 11.4（十億美元）在資本上。

  • $y^{2/5}$ 微分後忘了乘 $\dfrac{dy}{dx}$。沒有它，式子裡就沒有東西可以解。
  • 先把 $x = 32$、$y = 243$ 代進去再微分。代完全部是常數，微分是 0。先微分，再代數字。
  • 次方相除要相減：$x^{-2/5} \div x^{3/5} = x^{-1}$。減的時候正負號要小心，$y$ 那塊是 $\tfrac25 - \big(-\tfrac35\big) = 1$。
  • MRTS 要寫正的。「資本改變多少」則要說清楚是「減少」。
  • 計算機按 $32^{3/5}$ 沒加括號。

(a) $Q = 20(32)^{3/5}(243)^{2/5} = 20\cdot 8\cdot 9 = 1440$（十億美元）

(b) $20x^{3/5}y^{2/5} = 1440$，兩邊對 $x$ 微分：

$20\Big[\tfrac35x^{-2/5}y^{2/5} + \tfrac25x^{3/5}y^{-3/5}\,y'\Big] = 0$，所以 $y' = -\dfrac{3y}{2x}$

代入 $x = 32$、$y = 243$：$y' = -\dfrac{729}{64} \approx -11.4$

資本支出約減少 11.4（十億美元）；MRTS $\approx 11.4$

換個數字練一次：課本 3.6 #48 是同一型

某家具工廠每天的產出 $Q = 5x^{1/4}y^{3/4}$（千美元），$x$ 是勞動支出、$y$ 是資本支出（千美元）。(a) $x = 16$、$y = 81$ 時產出多少？(b) 產出不變，勞動多花 1（千美元）時資本該怎麼調整？MRTS 是多少？

(a) $16 = 2^4$、$81 = 3^4$，所以 $Q = 5\cdot 2\cdot 27 = 270$（千美元）。

(b) $x^{1/4}y^{3/4} = 54$ 兩邊微分：$\tfrac14x^{-3/4}y^{3/4} + \tfrac34x^{1/4}y^{-1/4}\,\dfrac{dy}{dx} = 0$，解得 $\dfrac{dy}{dx} = -\dfrac{y}{3x}$。

代入：$-\dfrac{81}{48} \approx -1.69$。資本約減少 1.69（千美元）；MRTS $\approx 1.69$。

③ 3.6 #44 雞蛋供給量

價格 $p$ 和供給量 $x$ 被一條方程式綁在一起。價格每週都在跌，問供給量每週掉多快。兩個量都隨著時間在變，所以這次不是對 $x$ 微分，而是對時間 $t$ 微分。這種題目叫「相關變率」。

先補觀念 1：「變得多快」就是對時間的導數

$\dfrac{dp}{dt}$ 讀作「$p$ 對時間的變化率」，意思是價格每週變多少。在漲是正的，在跌是負的。先把題目的每一句話翻成符號：

題目的句子翻成符號要注意的地方
市面上有 25,000 盒$x = 25$$x$ 的單位是千盒
價格每週每盒跌 2 美分$\dfrac{dp}{dt} = -0.02$$p$ 的單位是美元，2 美分是 0.02；下跌所以是負的
供給量下降得多快求 $\dfrac{dx}{dt}$答案的單位是千盒／週

先補觀念 2：對 t 微分，和前兩題是同一招

前兩題是「看到 $y$ 多乘 $\dfrac{dy}{dx}$」。現在 $p$ 和 $x$ 都是時間 $t$ 的函數，所以每個變數微分後，都要多乘「它自己對 $t$ 的變化率」：

$$\frac{d}{dt}\big(p^2\big) = 2p\,\frac{dp}{dt} \qquad\qquad \frac{d}{dt}\big(x^2\big) = 2x\,\frac{dx}{dt} \qquad\qquad \frac{d}{dt}\big(100\big) = 0$$

先補觀念 3：先微分，最後才代數字

$x = 25$ 只是「這一刻」的值，$x$ 本身還在變。如果一開始就把 25 代進方程式，$x$ 會變成常數，微分是 0，整題就做不下去。順序一定是：方程式 → 對 $t$ 微分 → 最後代數字。

價格在跌，供給量每週少多少

某品牌中型雞蛋的批發價 $p$（美元／盒）與每週供給量 $x$（千盒）滿足

$$625p^2 - x^2 = 100$$

某一週開始時市面上有 25,000 盒，而且價格正以每週每盒 2 美分的速度下跌。這時候每週供給量下降得多快？

提示

$$1250\,p\,\frac{dp}{dt} - 2x\,\frac{dx}{dt} = 0$$

現在才代數字

先補觀念 1：定義域和截距

定義域是「$x$ 可以代哪些數」。分式的分母不能是 0，所以把讓分母等於 0 的 $x$ 挖掉。

截距是圖形碰到座標軸的點：

  • $y$ 截距：代 $x = 0$ 算 $f(0)$。
  • $x$ 截距：解 $f(x) = 0$。分式等於 0，只要分子等於 0。

先補觀念 2：漸近線是圖形會貼近的直線

這題的函數是 $f(x) = \dfrac{x^2 - 9}{x^2 - 4}$。先看 $x$ 靠近 2、還有 $x$ 很大的時候，函數值怎麼跑：

水平漸近線：$x$ 跑到很遠時，函數值貼近的高度。寫成 $y = $ 某數。分子分母次數一樣時，就是最高次項的係數相除。

垂直漸近線兩側是往上還是往下，不用算極限：代一個很靠近的數，只看分子、分母的正負號。

先補觀念 3：符號圖怎麼讀

$f'$ 是斜率。$f' \gt 0$ 圖形往上走，$f' \lt 0$ 往下走。把 $f'$ 等於 0 或不存在的點標在數線上，每一段各代一個數看正負，就是符號圖。$f''$ 也畫一張：$f'' \gt 0$ 是 ∪ 形（凹向上），$f'' \lt 0$ 是 ∩ 形（凹向下）。

看到的符號變化結論
$f'$ 由 − 變 ＋（先下後上）相對極小值
$f'$ 由 ＋ 變 −（先上後下）相對極大值
$f''$ 變號，而且那個點在定義域裡反曲點

不在定義域裡的點（這題的 $x = \pm 2$）要標在符號圖上，但它們不會是極值，也不會是反曲點，因為圖形上根本沒有那個點。

先補觀念 4：分式的微分用除法規則

$$\Big(\frac{\text{上}}{\text{下}}\Big)' = \frac{\text{上}'\cdot\text{下} - \text{上}\cdot\text{下}'}{\text{下}^2}$$

順序是「上微乘下，減，上乘下微」，分母平方。減號兩邊不能對調。

一個消息在 3000 人的校園裡傳開。知道的人數一開始增加得慢，中間最快，快到 3000 人時又慢下來。公式裡有兩個還不知道的常數 $B$ 和 $k$，題目藏了兩個條件，剛好用來把它們求出來。求出來之後，再回答「4 小時後幾個人知道」和「那時候傳得多快」。

先補觀念 1：e 只是一個數字

$e \approx 2.718$，和 $\pi$ 一樣是一個固定的數。這題會用到它的三個性質：

性質意思這題哪裡用到
$e^0 = 1$任何數的 0 次方都是 1代 $t = 0$ 求 $B$
$e^{-x} = \dfrac{1}{e^x}$負次方是倒數；$x$ 越大，$e^{-x}$ 越接近 0解釋為什麼人數會貼近 3000
$\big(e^{a}\big)^2 = e^{2a}$次方的次方，指數相乘不按計算機就算出 $e^{-4k}$

計算機：$e^x$ 鍵通常在 ln 鍵的上方，要先按 SHIFT。指數是負的或是一串算式時，一定要加括號。試機：$e^{-1.622} \approx 0.1975$。

先補觀念 2：ln 是「e 的次方」的反操作

$\ln$ 回答的問題是「$e$ 的幾次方會等於這個數」。所以：

$$e^{\,\square} = c \quad\Longrightarrow\quad \square = \ln c$$

條件：$e$ 的那一項要先單獨留在一邊，才能取 $\ln$。

例：$e^{u} = 5$，那麼 $u = \ln 5 \approx 1.609$。再一個例子：$e^{-2k} = \dfrac49$，那麼 $-2k = \ln\dfrac49 \approx -0.8109$。小於 1 的數取 $\ln$ 會是負的，這是正常的。

計算機：按 ln ( 4 ÷ 9 ) = 得 $-0.8109$。不要按成 log，那是另一個鍵。

先補觀念 3：這條曲線長什麼樣子

公式是 $f(t) = \dfrac{3000}{1 + Be^{-kt}}$。時間 $t$ 很大時，$e^{-kt}$ 趨近 0，分母趨近 1，所以 $f(t)$ 趨近 3000。意思是：最後全校 3000 人都會知道，3000 就是上限。下面是把 $B$、$k$ 求出來之後的圖，先看形狀：

先補觀念 4：分母有東西的函數怎麼微分

$\dfrac{3000}{\text{一包}}$ 可以寫成 $3000\,(\text{一包})^{-1}$，用連鎖律：

$$\Big[3000\,(\text{一包})^{-1}\Big]' = -3000\,(\text{一包})^{-2}\cdot(\text{一包})'$$

這題的一包是 $1 + 9e^{-kt}$。它的微分：$1$ 變 $0$；$9e^{-kt}$ 照抄，再乘指數 $-kt$ 的微分 $-k$，得 $-9k\,e^{-kt}$。

求出 B 和 k，再算人數和傳播速度

某大學新大樓的落成典禮有 300 名學生參加。校長在典禮上宣布了新的擴建計畫。典禮後 $t$ 小時，知道這個消息的學生人數為

$$f(t) = \frac{3000}{1 + Be^{-kt}}$$

已知典禮後 2 小時，校園裡有 600 名學生知道這個消息。

(1) 典禮後 4 小時，有多少學生知道？
(2) 典禮後 4 小時那一刻，消息傳得多快？

提示

兩個條件：$t = 0$ 時是 300 人（在場的學生當下就知道了），$t = 2$ 時是 600 人。先用第一個求 $B$，再用第二個求 $k$。「傳得多快」就是 $f'(4)$。

用 t = 0 求 B

典禮當下（$t = 0$）在場的 300 人已經知道，所以 $f(0) = 300$。代 $t = 0$，$e^{0} = 1$：

$$\frac{3000}{1 + B\cdot 1} = 300 \quad\Longrightarrow\quad 1 + B = \frac{3000}{300} = 10 \quad\Longrightarrow\quad B = 9$$

用 t = 2 列出 k 的方程式

$f(2) = 600$，而且 $B = 9$：

$$\frac{3000}{1 + 9e^{-2k}} = 600 \quad\Longrightarrow\quad 1 + 9e^{-2k} = \frac{3000}{600} = 5$$

把 e 的那一項單獨留下

一層一層剝：先減 1，再除以 9。

$$9e^{-2k} = 4 \quad\Longrightarrow\quad e^{-2k} = \frac49$$

取 ln，解出 k

$$-2k = \ln\frac49 \approx -0.8109 \quad\Longrightarrow\quad k = \frac{-0.8109}{-2} \approx 0.4055$$

$k$ 是正的才合理（消息越傳越多人知道）。如果算出負的，就是正負號掉了。

現在公式完整了：$f(t) = \dfrac{3000}{1 + 9e^{-0.4055t}}$。

(1) 算 f(4)

要用到 $e^{-4k}$。有一個不用按計算機的算法：$e^{-4k} = \big(e^{-2k}\big)^2$，而上面剛算出 $e^{-2k} = \dfrac49$：

$$e^{-4k} = \Big(\frac49\Big)^2 = \frac{16}{81} \approx 0.1975$$ $$f(4) = \frac{3000}{1 + 9\cdot\frac{16}{81}} = \frac{3000}{1 + \frac{16}{9}} = \frac{3000}{\frac{25}{9}} = 3000\times\frac{9}{25} = 1080$$

用計算機也可以：$e^{-4\times 0.4055} = e^{-1.622} \approx 0.1975$，$1 + 9(0.1975) = 2.7778$，$3000 \div 2.7778 \approx 1080$。

(2) 先求導數 f′(t)

改寫成 $f(t) = 3000\,(1 + 9e^{-kt})^{-1}$，用連鎖律。裡面那包的微分是 $-9k\,e^{-kt}$：

$$f'(t) = -3000\,(1 + 9e^{-kt})^{-2}\cdot\big(-9k\,e^{-kt}\big) = \frac{27000\,k\,e^{-kt}}{(1 + 9e^{-kt})^2}$$

兩個負號相乘變正，$3000 \times 9 = 27000$。

代 t = 4

需要的數字上一步都有了：$k \approx 0.4055$，$e^{-4k} \approx 0.1975$，$1 + 9e^{-4k} \approx 2.7778$。

$$f'(4) = \frac{27000\,(0.4055)(0.1975)}{(2.7778)^2} \approx \frac{2162.3}{7.716} \approx 280$$

單位是「人／小時」。意思是典禮後 4 小時那一刻，每小時大約多 280 個學生知道這個消息。

(1) 4 小時後有 1080 名學生知道。(2) 那一刻消息以每小時大約 280 人的速度傳開。

  • 沒發現 $t = 0$ 這個條件。「300 名學生參加典禮」就是 $f(0) = 300$。
  • 把 $e^0$ 當成 0。$e^0 = 1$，所以 $f(0) = \dfrac{3000}{1 + B}$。
  • $1 + 9e^{-2k} = 5$ 還沒整理就取 $\ln$。要先減 1、再除以 9，讓 $e^{-2k}$ 單獨在一邊。
  • $k$ 太早四捨五入。用 $k = 0.41$ 會算出 1093 人，不是 1080。$k$ 至少留四位小數，或用 $\big(\tfrac49\big)^2$ 的算法。
  • 微分時漏掉連鎖律多出來的 $-k$，或是兩個負號沒有變正。傳播速度應該是正的。
  • 計算機的負指數沒加括號。
  • 第 (2) 小題沒寫單位。答案是「人／小時」。

$f(0) = 300$：$\dfrac{3000}{1 + B} = 300$，得 $B = 9$

$f(2) = 600$：$1 + 9e^{-2k} = 5$，$e^{-2k} = \dfrac49$，$k = -\dfrac12\ln\dfrac49 \approx 0.4055$

(1) $e^{-4k} = \big(\tfrac49\big)^2 = \tfrac{16}{81}$，$f(4) = \dfrac{3000}{1 + 9\cdot\frac{16}{81}} = 1080$（人）

(2) $f'(t) = \dfrac{27000\,k\,e^{-kt}}{(1 + 9e^{-kt})^2}$，$f'(4) = \dfrac{27000(0.4055)(0.1975)}{(2.7778)^2} \approx 280$（人／小時）

換個問法練一次：典禮後多久，全校一半的人（1500 人）知道？

令 $f(t) = 1500$：$\dfrac{3000}{1 + 9e^{-kt}} = 1500$，所以 $1 + 9e^{-kt} = 2$，$e^{-kt} = \dfrac19$。

取 $\ln$：$-kt = \ln\dfrac19 = -\ln 9$，所以 $t = \dfrac{\ln 9}{k} \approx \dfrac{2.1972}{0.4055} \approx 5.42$ 小時。

補充：這種 S 形曲線在「剛好一半」的時候傳得最快（那裡是反曲點）。回到上面的圖按「t = 5.42」，速度大約是每小時 304 人，比 $t = 4$ 的 280 還快。
