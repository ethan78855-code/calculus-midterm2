第 3 章

收益 $R(x) = p\,x$　　利潤 $P(x) = R(x) - C(x)$　　平均成本 $\bar{C}(x) = \dfrac{C(x)}{x}$

邊際成本 $C'(x)$、邊際收益 $R'(x)$、邊際利潤 $P'(x)$、邊際平均成本 $\bar{C}'(x)$

$C'(x) \approx$ 生產第 $x+1$ 個的成本

$$E(p) = -\frac{p\,f'(p)}{f(p)} \qquad (x = f(p))$$

$E \gt 1$ 有彈性：漲價收益減少　　$E \lt 1$ 無彈性：漲價收益增加　　$E = 1$ 單一彈性

$f''(x) = \big(f'(x)\big)'$，$f'''(x) = \big(f''(x)\big)'$。位置 $s(t)$、速度 $v = s'(t)$、加速度 $a = s''(t)$。

把 $y$ 當成 $x$ 的函數，微分時多乘 $\dfrac{dy}{dx}$：

$$\frac{d}{dx}\,y^n = n\,y^{n-1}\frac{dy}{dx} \qquad \frac{d}{dx}(xy) = y + x\frac{dy}{dx}$$

相關變率：把每個變數都當成 $t$ 的函數，兩邊對 $t$ 微分，微完才代數字。

第 4 章

$f'(x) \gt 0$ 遞增，$f'(x) \lt 0$ 遞減。

臨界數：定義域內讓 $f'(c) = 0$ 或 $f'(c)$ 不存在的 $c$。

一階導數檢定：$f'$ 由正變負是相對極大值；由負變正是相對極小值；不變號就不是極值。

$f''(x) \gt 0$ 凹向上，$f''(x) \lt 0$ 凹向下。反曲點：$f''$ 變號的點（要在圖形上）。

二階導數檢定：$f'(c) = 0$ 時，$f''(c) \lt 0$ 是相對極大值，$f''(c) \gt 0$ 是相對極小值，$f''(c) = 0$ 無法判斷。

垂直漸近線 $x = a$：分母為 0 而分子不為 0。

水平漸近線 $y = b$：$\lim\limits_{x \to \pm\infty} f(x) = b$。有理函數比最高次方：分子次數小得 $y = 0$；次數相同得首項係數的比；分子次數大就沒有。

畫圖順序：定義域 → 截距 → $x \to \pm\infty$ → 漸近線 → $f'$ 符號圖 → 極值 → $f''$ 符號圖 → 反曲點 → 描圖。

在 $[a, b]$ 上：找出 $(a, b)$ 內所有臨界數，計算臨界數和兩個端點的函數值，最大的是絕對極大值，最小的是絕對極小值。

  1. 畫圖、設變數。
  2. 寫出要最大或最小的量（目標函數）。
  3. 用題目的限制條件，把目標函數消成只有一個變數。
  4. 寫出變數的合理範圍。
  5. 微分等於 0 找臨界數，用端點比較或二階導數確認。

常用：矩形面積 $xy$、周長 $2x + 2y$；盒子體積 $=$ 底面積 $\times$ 高；圓面積 $\pi r^2$、圓周 $2\pi r$；圓柱體積 $\pi r^2 h$、側面積 $2\pi r h$；時間 $=$ 距離 $\div$ 速度；斜邊 $= \sqrt{a^2 + b^2}$。

第 5 章

$$b^x b^y = b^{x+y} \qquad \frac{b^x}{b^y} = b^{x-y} \qquad (b^x)^y = b^{xy} \qquad b^0 = 1 \qquad b^{-x} = \frac{1}{b^x}$$ $$\log_b mn = \log_b m + \log_b n \qquad \log_b \frac{m}{n} = \log_b m - \log_b n \qquad \log_b m^n = n\log_b m$$

$y = \log_b x$ 的意思是 $b^y = x$。$\ln$ 是以 $e$ 為底的對數：$\ln e^x = x$，$e^{\ln x} = x$，$\ln 1 = 0$，$\ln e = 1$。

解 $e^{kt} = c$：兩邊取 $\ln$，得 $t = \dfrac{\ln c}{k}$。

$$A = P\left(1 + \frac{r}{m}\right)^{mt} \qquad \text{連續複利 } A = Pe^{rt}$$

$P$ 本金、$r$ 年利率（小數）、$m$ 每年複利次數、$t$ 年數。

有效年利率 $r_{\text{eff}} = \left(1 + \dfrac{r}{m}\right)^m - 1$　　現值 $P = A\left(1 + \dfrac{r}{m}\right)^{-mt}$ 或 $P = Ae^{-rt}$

模型公式$t = 0$$t \to \infty$
指數成長$Q_0 e^{kt}$$Q_0$無限大
指數衰退$Q_0 e^{-kt}$$Q_0$$0$
學習曲線$C - Ae^{-kt}$$C - A$$C$
邏輯斯成長$\dfrac{A}{1 + Be^{-kt}}$$\dfrac{A}{1 + B}$$A$

半衰期 $= \dfrac{\ln 2}{k}$。問「多快」就微分：例如 $\big(Q_0e^{kt}\big)' = kQ_0e^{kt}$。

計算機按法

  1. $e^{-0.8}$：按 SHIFT + ln（就是 $e^x$），輸入 (−0.8)，應該得到 0.4493。指數是負數或算式時要加括號。
  2. $\ln 1.5$：按 ln，輸入 1.5，應該得到 0.4055。log 鍵是以 10 為底，不要按錯。
  3. $1.02^{20}$：輸入 1.02，按 ^ 或 xy，輸入 20，應該得到 1.4859。
  4. $\dfrac{1000}{1 + 199e^{-0.8}}$：分母要整個括起來，應該得到 11.06。
  5. 中間過程不要先四捨五入，用計算機的 Ans 鍵接著算，最後才取位數。

最常被扣分的地方

  • 連鎖律忘記乘「裡面的微分」。
  • 除法規則分子寫成加號，或上下順序顛倒。
  • 隱函數微分時，$y^2$ 微成 $2y$ 忘記乘 $y'$；$xy$ 沒有用乘法規則。
  • 相關變率太早代數字（常數微分變成 0，整題就錯了）。
  • 臨界數沒有檢查是不是在定義域裡（例如 $x = 0$ 讓分母為 0）。
  • $f''(c) = 0$ 就直接說是反曲點，沒有檢查 $f''$ 有沒有變號。
  • 閉區間求最大最小值，忘記算端點。
  • 應用題算出 $x$ 就停了，沒有回答題目問的尺寸、金額或時間，也沒寫單位。
  • 彈性題沒寫結論（有彈性或無彈性；收益增加或減少）。
  • $e^{-0.05t}$ 微分忘記乘 $-0.05$；$\ln$ 和 $\log$ 按錯鍵。
