第 3 章 · Section 3.6

隱函數微分與相關變率

到目前為止，題目都是 $y = \text{一堆 } x$ 的樣子。這一節處理 $x$ 和 $y$ 混在一起、$y$ 沒有被單獨解出來的方程式。做法只有一個重點：看到 $y$ 微分，後面要多乘一個 $\dfrac{dy}{dx}$。後半段的「相關變率」是同一招，只是改成對時間 $t$ 微分。

顯函數與隱函數

$y = x^2 + 1$ 這種「$y$ 自己在等號一邊」的叫顯函數。像 $x^2 + y^2 = 25$ 這種 $x$、$y$ 攪在一起的叫隱函數：$y$ 還是跟著 $x$ 變，只是關係藏在方程式裡。

$x^2 + y^2 = 25$ 是半徑 5 的圓。硬要解出 $y$ 會得到 $y = \pm\sqrt{25 - x^2}$，有正負兩支，還要對根號微分，很麻煩。

隱函數微分的想法：不用把 $y$ 解出來，直接把整條方程式的兩邊一起微分，最後再把 $\dfrac{dy}{dx}$ 解出來。

先看結果。對圓 $x^2 + y^2 = 25$ 做隱函數微分會得到 $\dfrac{dy}{dx} = -\dfrac{x}{y}$（下一段教怎麼算）。拖曳圖上的點，看切線斜率是不是真的等於 $-x/y$：

隱函數微分三步驟

  1. 等號兩邊同時對 $x$ 微分。
  2. 只有 $x$ 的項照平常微。含 $y$ 的項，把 $y$ 當成「一包 $x$ 的函數」，用連鎖律：照微之後多乘一個 $\dfrac{dy}{dx}$。
  3. 把有 $\dfrac{dy}{dx}$ 的項全部移到同一邊，提出來，解出 $\dfrac{dy}{dx}$。

為什麼要多乘 $\dfrac{dy}{dx}$？因為 $y$ 裡面藏著 $x$。$y^2$ 其實是 $\big[y(x)\big]^2$，跟 $(2x+1)^2$ 一樣是「外面平方、裡面一包」，連鎖律要乘上裡面那包的微分，而 $y$ 的微分就是 $\dfrac{dy}{dx}$。

$$\frac{d}{dx}\big(y^n\big) = n\,y^{n-1}\cdot\frac{dy}{dx} \qquad\qquad \frac{d}{dx}\big(xy\big) = \underbrace{1\cdot y}_{\text{前微}} + \underbrace{x\cdot\frac{dy}{dx}}_{\text{後微}}$$

$xy$ 是 $x$ 和 $y$ 相乘，要用乘法規則。

例 1：$x^2 + y^2 = 25$。兩邊對 $x$ 微分（右邊 25 是常數，微分是 0）：

$$2x + 2y\,\frac{dy}{dx} = 0 \quad\Longrightarrow\quad 2y\,\frac{dy}{dx} = -2x \quad\Longrightarrow\quad \frac{dy}{dx} = -\frac{x}{y}$$

例 2（有 $xy$）：$x^2 - 2xy = 6$。中間那項是 $-2$ 乘上 $xy$，用乘法規則：

$$2x - 2\Big(y + x\,\frac{dy}{dx}\Big) = 0 \quad\Longrightarrow\quad 2x - 2y - 2x\,\frac{dy}{dx} = 0 \quad\Longrightarrow\quad \frac{dy}{dx} = \frac{x - y}{x}$$

例 3（$\dfrac{dy}{dx}$ 出現兩次）：$x^3 + y^3 + y - 4 = 0$。

$$3x^2 + 3y^2\,\frac{dy}{dx} + \frac{dy}{dx} = 0 \quad\Longrightarrow\quad \big(3y^2 + 1\big)\frac{dy}{dx} = -3x^2 \quad\Longrightarrow\quad \frac{dy}{dx} = -\frac{3x^2}{3y^2 + 1}$$

有兩項帶 $\dfrac{dy}{dx}$ 時，把它提出來變成一個括號，再除過去。指定題 #23 就需要這一步。

三個最常見的錯：

  • $\dfrac{d}{dx}(y^2)$ 只寫 $2y$，忘了乘 $\dfrac{dy}{dx}$。
  • $\dfrac{d}{dx}(xy)$ 寫成 $\dfrac{dy}{dx}$ 或 $y$，沒有用乘法規則。
  • 等號右邊的常數忘了微分成 0，或右邊有 $x$ 卻忘了微。

隱函數微分時，$\dfrac{d}{dx}\big(y^3\big)$ 是？

$y$ 是 $x$ 的函數，連鎖律：外層微分 $3y^2$，再乘上 $y$ 自己的微分 $\dfrac{dy}{dx}$。

$x^2 + xy = 10$，$\dfrac{dy}{dx}$ 是？

兩邊微分：$2x + \Big(y + x\dfrac{dy}{dx}\Big) = 0$，所以 $x\dfrac{dy}{dx} = -2x - y$，$\dfrac{dy}{dx} = -\dfrac{2x+y}{x}$。

求某一點的切線

題目如果給了點，把座標代進 $\dfrac{dy}{dx}$ 就是切線斜率，再用點斜式 $y - y_0 = m(x - x_0)$。

例：求 $4x^2 + 9y^2 = 36$ 在點 $(0, 2)$ 的切線

兩邊微分：$8x + 18y\,\dfrac{dy}{dx} = 0$，所以 $\dfrac{dy}{dx} = -\dfrac{4x}{9y}$。代 $(0, 2)$ 得斜率 $0$，切線是水平線 $y = 2$。

相關變率

兩個量被一條關係式綁在一起，其中一個隨時間在變，另一個就會跟著變。已知一個變多快，求另一個變多快，這就是相關變率。

這裡所有變數都是時間 $t$ 的函數，所以改成兩邊對 $t$ 微分。規則跟隱函數微分一模一樣，只是現在每個變數後面都要乘上「它自己對 $t$ 的變率」：

$$\frac{d}{dt}\big(x^2\big) = 2x\,\frac{dx}{dt} \qquad \frac{d}{dt}\big(p^2\big) = 2p\,\frac{dp}{dt} \qquad \frac{d}{dt}\big(\pi r^2\big) = 2\pi r\,\frac{dr}{dt}$$

$\dfrac{dx}{dt}$ 讀作「$x$ 對時間的變化率」。在增加是正的，在減少是負的。

  1. 列出題目給的數字：哪些是「量」（如 $x = 25$），哪些是「變率」（如 $\dfrac{dp}{dt} = -0.02$）。
  2. 寫下要求的是哪個變率（如 $\dfrac{dx}{dt}$）。
  3. 寫出連結這些變數的關係式（題目給的方程式，或幾何公式）。
  4. 兩邊對 $t$ 微分。
  5. 最後才把數字代進去，解出答案，寫上單位。

一定要先微分、再代數字。如果先把 $x = 25$ 代進方程式，$x$ 就變成常數，微分會變 0，整題就錯了。

例 1：油污擴散

油輪漏油，海面上的油污是一個圓。當半徑是 60 英尺、而且半徑以每秒 $\tfrac12$ 英尺的速度變大時，油污面積增加得多快？

已知 $r = 60$，$\dfrac{dr}{dt} = \tfrac12$；求 $\dfrac{dA}{dt}$。關係式是圓面積 $A = \pi r^2$，對 $t$ 微分再代入：

$$\frac{dA}{dt} = 2\pi r\,\frac{dr}{dt} = 2\pi(60)\Big(\frac12\Big) = 60\pi \approx 188.5 \text{ 平方英尺/秒}$$

例 2：兩台車的距離

兩台車同時離開路口，一台往西、一台往北。某一刻，往西的車離路口 20 英尺、速度 9 英尺/秒；往北的車離路口 28 英尺、速度 11 英尺/秒。兩車之間的距離變化得多快？

已知 $x = 20$，$y = 28$，$\dfrac{dx}{dt} = 9$，$\dfrac{dy}{dt} = 11$；求 $\dfrac{dD}{dt}$。關係式是畢氏定理 $D^2 = x^2 + y^2$。對 $t$ 微分：

$$2D\,\frac{dD}{dt} = 2x\,\frac{dx}{dt} + 2y\,\frac{dy}{dt} \quad\Longrightarrow\quad \frac{dD}{dt} = \frac{x\,\dfrac{dx}{dt} + y\,\dfrac{dy}{dt}}{D}$$

這一刻 $D = \sqrt{20^2 + 28^2} = \sqrt{1184} \approx 34.41$，所以

$$\frac{dD}{dt} = \frac{20(9) + 28(11)}{34.41} = \frac{488}{34.41} \approx 14.2 \text{ 英尺/秒}$$

例 3：價格和需求量（跟指定題同一型）

某輪胎每週需求量 $x$（千條）與單價 $p$（美元）滿足 $p + x^2 = 144$。當 $x = 9$、$p = 63$，而且價格每週上漲 2 美元時，需求量變化得多快？

已知 $\dfrac{dp}{dt} = 2$，求 $\dfrac{dx}{dt}$。兩邊對 $t$ 微分：

$$\frac{dp}{dt} + 2x\,\frac{dx}{dt} = 0 \quad\Longrightarrow\quad \frac{dx}{dt} = -\frac{1}{2x}\cdot\frac{dp}{dt} = -\frac{2}{2(9)} = -\frac19 \approx -0.111$$

$x$ 的單位是千條，所以需求量每週大約減少 111 條。答案是負的，剛好符合「漲價，買的人變少」。

正方形的邊長 $s$ 以每秒 2 公分的速度變長。邊長是 5 公分的那一刻，面積 $A = s^2$ 增加得多快？

對 $t$ 微分：$\dfrac{dA}{dt} = 2s\,\dfrac{ds}{dt} = 2(5)(2) = 20$。記得要乘 $\dfrac{ds}{dt}$。

指定題

#19、#23 是隱函數微分，#44 是相關變率。先自己寫，卡住再開解答。

根號裡有 y 的隱函數微分

用隱函數微分求 $\dfrac{dy}{dx}$：

$$\sqrt{x + y} = x$$
提示

先把左邊寫成 $(x+y)^{1/2}$。用連鎖律時，裡面那包 $x + y$ 的微分是 $1 + \dfrac{dy}{dx}$，不是 1。

改寫成次方

$$(x + y)^{1/2} = x$$

兩邊對 x 微分

左邊用連鎖律：外層 $\tfrac12$ 次方，裡面 $x + y$ 的微分是 $1 + \dfrac{dy}{dx}$。右邊 $x$ 的微分是 1。

$$\frac12(x + y)^{-1/2}\Big(1 + \frac{dy}{dx}\Big) = 1 \qquad\text{也就是}\qquad \frac{1 + \dfrac{dy}{dx}}{2\sqrt{x + y}} = 1$$

解出 dy/dx

兩邊同乘 $2\sqrt{x+y}$，再把 1 移過去：

$$1 + \frac{dy}{dx} = 2\sqrt{x + y} \quad\Longrightarrow\quad \frac{dy}{dx} = 2\sqrt{x + y} - 1$$

用圖形檢查

這題其實可以解出 $y$：兩邊平方得 $x + y = x^2$，所以 $y = x^2 - x$（$x \ge 0$），直接微分是 $2x - 1$。而原式說 $\sqrt{x+y} = x$，所以 $2\sqrt{x+y} - 1$ 就是 $2x - 1$，兩種算法一致。

$\dfrac{dy}{dx} = 2\sqrt{x + y} - 1$

根號裡有 xy 的隱函數微分

用隱函數微分求 $\dfrac{dy}{dx}$：

$$\sqrt{xy} = x + y$$
提示

左邊 $(xy)^{1/2}$ 用連鎖律，裡面那包 $xy$ 要用乘法規則，微分是 $y + x\dfrac{dy}{dx}$。這題 $\dfrac{dy}{dx}$ 會出現在等號兩邊，要移項之後提出來。

改寫成次方

$$(xy)^{1/2} = x + y$$

兩邊對 x 微分

左邊：外層 $\tfrac12$ 次方，裡面 $xy$ 的微分是 $y + x\dfrac{dy}{dx}$。右邊：$x + y$ 的微分是 $1 + \dfrac{dy}{dx}$。

$$\frac12(xy)^{-1/2}\Big(y + x\,\frac{dy}{dx}\Big) = 1 + \frac{dy}{dx}$$

去掉分母

$\tfrac12(xy)^{-1/2} = \dfrac{1}{2\sqrt{xy}}$，兩邊同乘 $2\sqrt{xy}$：

$$y + x\,\frac{dy}{dx} = 2\sqrt{xy} + 2\sqrt{xy}\,\frac{dy}{dx}$$

把有 dy/dx 的項移到左邊，其他移到右邊

$$x\,\frac{dy}{dx} - 2\sqrt{xy}\,\frac{dy}{dx} = 2\sqrt{xy} - y$$

提出 dy/dx，除過去

$$\big(x - 2\sqrt{xy}\big)\frac{dy}{dx} = 2\sqrt{xy} - y \quad\Longrightarrow\quad \frac{dy}{dx} = \frac{2\sqrt{xy} - y}{x - 2\sqrt{xy}}$$

$\dfrac{dy}{dx} = \dfrac{2\sqrt{xy} - y}{x - 2\sqrt{xy}}$

雞蛋的價格與供給量

某品牌中型雞蛋的批發價 $p$（美元/盒）與每週供給量 $x$（千盒）滿足

$$625p^2 - x^2 = 100$$

某一週開始時市面上有 25,000 盒，而且價格正以每週每盒 2 美分的速度下跌。這時候每週供給量下降得多快？

提示

25,000 盒是 $x = 25$（單位是千盒）。2 美分是 0.02 美元，而且是下跌，所以 $\dfrac{dp}{dt} = -0.02$。題目沒給 $p$，要先把 $x = 25$ 代回方程式求出來；但這個 $p$ 要等微分完才代。

整理已知和所求

已知：$x = 25$，$\dfrac{dp}{dt} = -0.02$（下跌所以是負的）。所求：$\dfrac{dx}{dt}$。

求這一刻的價格 p

把 $x = 25$ 代入方程式：

$$625p^2 - 625 = 100 \quad\Longrightarrow\quad p^2 = \frac{725}{625} = 1.16 \quad\Longrightarrow\quad p = \sqrt{1.16} \approx 1.077$$

價格是正的，取正根。

方程式兩邊對 t 微分

$p$ 和 $x$ 都是時間的函數，右邊 100 是常數：

$$1250\,p\,\frac{dp}{dt} - 2x\,\frac{dx}{dt} = 0$$

解出 dx/dt

$$2x\,\frac{dx}{dt} = 1250\,p\,\frac{dp}{dt} \quad\Longrightarrow\quad \frac{dx}{dt} = \frac{625\,p}{x}\cdot\frac{dp}{dt}$$

代入數字

$$\frac{dx}{dt} = \frac{625(1.077)}{25}\,(-0.02) \approx -0.5385 \text{（千盒/週）}$$

$-0.5385$ 千盒就是大約 $-539$ 盒。負號代表在減少。

$\dfrac{dx}{dt} \approx -0.539$ 千盒/週，也就是每週供給量大約減少 539 盒。

隱函數微分的答案通常同時有 $x$ 和 $y$，不用硬化成只有 $x$。相關變率要注意三件事：「下跌、減少」的變率要寫負號；單位要對（2 美分 = 0.02 美元，25,000 盒 = 25 千盒）；最後用一句話回答，例如「供給量每週約減少 539 盒」。
