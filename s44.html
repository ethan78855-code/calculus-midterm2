第 4 章 · Section 4.4

最佳化 I：絕對極值

4.1 找的是「附近最高、附近最低」的相對極值。這一節要找的是整個區間裡真正的最大值和最小值。方法只有一招：把幾個候選點的函數值算出來，比大小。這一節沒有指定題，但它是 4.5 應用題的最後一步。

絕對極值和相對極值差在哪

絕對極大值：整個定義範圍內最大的函數值。也就是對範圍內所有 $x$ 都有 $f(x) \le f(c)$。
絕對極小值：整個定義範圍內最小的函數值。

相對極值是「這座山的山頂」，絕對極值是「整條路線的最高點」。最高點可能是某座山頂，也可能是路線的起點或終點。所以端點一定要檢查。

什麼時候保證有最大和最小

如果 $f$ 在閉區間 $[a, b]$ 上連續，那麼 $f$ 在 $[a, b]$ 上一定有絕對極大值和絕對極小值。

兩個條件都要有。少一個就可能沒有：

  • 區間不含端點，例如 $f(x) = x$ 在 $(0, 1)$：越靠近 1 越大，但永遠到不了 1，沒有最大值。
  • 函數不連續，例如 $f(x) = \dfrac1x$ 在 $[-1, 1]$：在 0 附近衝到無限大。

閉區間法：列表比大小

  1. 微分，找出 $(a, b)$ 裡面所有的臨界數（$f'(x) = 0$ 或 $f'(x)$ 不存在的點）。不在區間裡的丟掉。
  2. 把每個臨界數和兩個端點 $a$、$b$ 代回原函數 $f$，算出函數值。
  3. 最大的就是絕對極大值，最小的就是絕對極小值。

這個方法不用畫符號圖，也不用判斷是相對極大還是極小，直接比數字就好。

  • 忘記算端點。這是這一節最常見的失分。
  • 把區間外的臨界數也拿來比。
  • 代回去的時候代到 $f'$ 而不是 $f$。要比的是「高度」，所以代原函數。
  • 答案要寫清楚：絕對極大值是函數值 $f(c)$，發生在 $x = c$。兩個都要寫。

$f(x) = x^2$ 在 $[-1, 2]$ 上。絕對極大值和絕對極小值分別是？

$f'(x) = 2x = 0$ 得臨界數 $x = 0$。比較 $f(-1) = 1$、$f(0) = 0$、$f(2) = 4$：最大是 4（在右端點），最小是 0（在臨界數）。

不是閉區間的時候

應用題的範圍常常是 $(0, \infty)$ 這種沒有端點的區間，例如產量 $x \gt 0$。這時用下面這個判斷：

如果 $f$ 在區間內只有一個臨界數 $c$，而且 $f(c)$ 是相對極小值（例如 $f''(c) \gt 0$），那它就是整個區間的絕對極小值。相對極大值同理。

只有一個谷底、沒有別的轉彎，曲線往兩邊都只能往上走，所以那個谷底就是全場最低。4.5 的應用題幾乎都是用這一條收尾：微分等於 0 解出唯一的臨界數，再用 $f''$ 的正負號確認。

$f(x) = x + \dfrac{4}{x}$ 在 $(0, \infty)$ 上只有一個臨界數 $x = 2$，且 $f''(2) \gt 0$。可以下什麼結論？

唯一的臨界數，而且 $f'' \gt 0$（凹向上、是谷底），所以是絕對極小值。$f(2) = 2 + 2 = 4$。

商管題的兩個標準問法

題目問要做的事和 3.4 的關係
生產多少利潤最大解 $P'(x) = 0$等於解 $R'(x) = C'(x)$：邊際收益 = 邊際成本

求 $f$ 在 $[0, 3]$ 的絕對極值，解 $f'(x) = 0$ 得到 $x = -\tfrac23$ 和 $x = 2$。要比較哪些函數值？

$-\tfrac23$ 不在 $[0, 3]$ 裡，要丟掉。候選人是兩個端點 0、3 和區間內的臨界數 2。

例題

這一節沒有指定題，下面四題是課本這一節最典型的題型。

例題 1：多項式在閉區間上

求 $f(x) = x^3 - 2x^2 - 4x + 4$ 在 $[0, 3]$ 上的絕對極大值與絕對極小值。

找臨界數

$$f'(x) = 3x^2 - 4x - 4 = (3x + 2)(x - 2)$$

$f'(x) = 0$ 得 $x = -\tfrac23$ 或 $x = 2$。$-\tfrac23$ 不在 $[0, 3]$ 內，丟掉。只剩 $x = 2$。

列表比大小

$x$身分$f(x)$
0左端點4
2臨界數$8 - 8 - 8 + 4 = -4$
3右端點$27 - 18 - 12 + 4 = 1$

下結論

絕對極大值 $f(0) = 4$；絕對極小值 $f(2) = -4$。

例題 2：導數不存在的臨界數

求 $f(x) = x^{2/3}$ 在 $[-1, 8]$ 上的絕對極大值與絕對極小值。

找臨界數

$$f'(x) = \frac23 x^{-1/3} = \frac{2}{3\sqrt[3]{x}}$$

分子是 2，所以 $f'$ 永遠不會等於 0。但是 $x = 0$ 時分母為 0，$f'(0)$ 不存在，而 0 在定義域裡，所以 $x = 0$ 是臨界數。

列表比大小

$f(-1) = \left(\sqrt[3]{-1}\right)^2 = 1$　　$f(0) = 0$　　$f(8) = \left(\sqrt[3]{8}\right)^2 = 4$

絕對極大值 $f(8) = 4$；絕對極小值 $f(0) = 0$。

例題 3：利潤最大

某公司每月生產並賣出 $x$ 組音響的利潤（美元）是

$$P(x) = -0.02x^2 + 300x - 200000 \qquad (0 \le x \le 20000)$$

每月應該生產幾組，利潤才會最大？最大利潤是多少？

找臨界數

$$P'(x) = -0.04x + 300 = 0 \quad\Rightarrow\quad x = \frac{300}{0.04} = 7500$$

比較臨界數與端點

$P(0) = -200000$（沒賣還是要付固定成本）
$P(7500) = -0.02(7500)^2 + 300(7500) - 200000 = -1125000 + 2250000 - 200000 = 925000$
$P(20000) = -8000000 + 6000000 - 200000 = -2200000$

每月生產 7500 組，最大利潤 925,000 美元。

例題 4：平均成本最低

每天生產 $x$ 個產品的總成本（美元）是 $C(x) = 0.0001x^2 + 4x + 400$。每天生產幾個，平均成本最低？最低平均成本是多少？

先寫出平均成本

$$\bar{C}(x) = \frac{C(x)}{x} = 0.0001x + 4 + \frac{400}{x} \qquad (x \gt 0)$$

範圍是 $(0, \infty)$，沒有端點，所以用「只有一個臨界數」的判斷。

微分找臨界數

$$\bar{C}'(x) = 0.0001 - \frac{400}{x^2} = 0 \quad\Rightarrow\quad x^2 = \frac{400}{0.0001} = 4000000 \quad\Rightarrow\quad x = 2000$$

$x = -2000$ 不合（產量不能是負的）。

確認是最小

$$\bar{C}''(x) = \frac{800}{x^3} \gt 0 \quad (x \gt 0)$$

凹向上，而且 $(0, \infty)$ 內只有這一個臨界數，所以 $x = 2000$ 給出絕對極小值。

代回去

$$\bar{C}(2000) = 0.0001(2000) + 4 + \frac{400}{2000} = 0.2 + 4 + 0.2 = 4.4$$

順便看邊際成本：$C'(x) = 0.0002x + 4$，$C'(2000) = 4.4$。平均成本最低的時候，剛好等於邊際成本。

每天生產 2000 個，最低平均成本是每個 4.4 美元。

看到「在區間 $[a, b]$ 上」這幾個字，就是閉區間法：臨界數加兩個端點，列表比大小。看到應用題沒有給區間，就是解 $f' = 0$ 找唯一的臨界數，再用 $f''$ 確認。答案要同時寫出「值是多少」和「發生在哪個 $x$」。
