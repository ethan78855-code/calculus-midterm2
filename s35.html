第 3 章 · Section 3.5

高階導數

「高階導數」聽起來很難，其實只是微分完再微分一次。這一節要會兩件事：算得出二階、三階導數，以及說得出二階導數代表什麼。第 4 章判斷圖形怎麼彎，全靠二階導數。

二階導數：把導數再微分一次

$f(x)$ 微分一次得到 $f'(x)$。$f'(x)$ 本身也是一個函數，所以可以再微分，得到的東西叫二階導數，寫成 $f''(x)$。再微一次就是三階導數 $f'''(x)$，可以一直微下去。

微分幾次名稱撇號寫法$\dfrac{d}{dx}$ 寫法
1 次一階導數$f'(x)$、$y'$$\dfrac{dy}{dx}$
2 次二階導數$f''(x)$、$y''$$\dfrac{d^2y}{dx^2}$
3 次三階導數$f'''(x)$、$y'''$$\dfrac{d^3y}{dx^3}$
$n$ 次$n$ 階導數$f^{(n)}(x)$$\dfrac{d^ny}{dx^n}$

撇號超過三個不好讀，所以四階以上改寫成 $f^{(4)}(x)$。括號不能省，$f^{(4)}$ 是微分四次，$f^4$ 是四次方。

例：$f(x) = x^4 - 2x^3 + 6x^2 - 3x + 10$，一路微到變成 0：

$$\begin{aligned} f'(x) &= 4x^3 - 6x^2 + 12x - 3\\ f''(x) &= 12x^2 - 12x + 12\\ f'''(x) &= 24x - 12\\ f^{(4)}(x) &= 24\\ f^{(5)}(x) &= 0 \end{aligned}$$

每微一次，多項式的次數就少 1。四次多項式微四次剩常數，微第五次變 0。算高階導數沒有新規則，就是把上一行的答案當成新題目再微一次。

$f''(x)$ 不是 $\big[f'(x)\big]^2$。二階導數是「再微分一次」，不是「平方」。例如 $f(x) = x^3$：$f'(x) = 3x^2$，$f''(x) = 6x$，而不是 $9x^4$。

$f(x) = x^3 - 4x^2 + 7$，$f''(x)$ 是？

先微一次：$f'(x) = 3x^2 - 8x$。再微一次：$f''(x) = 6x - 8$。第一個選項只微了一次。

f″ 的意思：變化率的變化率

$f'(x)$ 是切線斜率，告訴你 $f$ 變化得多快。$f''(x)$ 是「$f'$ 的導數」，所以它告訴你斜率本身變化得多快：

$f''(x) \gt 0$：切線斜率正在變大，曲線往上彎（像碗 ∪）
$f''(x) \lt 0$：切線斜率正在變小，曲線往下彎（像蓋子 ∩）

「曲線往上彎或往下彎」在 4.2 節有正式的名字，叫凹向上、凹向下。現在先有這個印象就好。

位置、速度、加速度

高階導數最直接的例子是車子的運動。$s(t)$ 是車子在時間 $t$ 的位置：

$$v(t) = s'(t) \qquad\qquad a(t) = v'(t) = s''(t)$$

速度是位置的變化率；加速度是速度的變化率，所以是位置的二階導數。

假設一台車的位置是 $s(t) = t^3 - 6t^2 + 9t$（公尺），那麼

$$v(t) = 3t^2 - 12t + 9 \qquad\qquad a(t) = 6t - 12$$

課本型例題：工地有一把鐵鎚從 256 英尺高掉下來，落下的距離是 $s = 16t^2$（英尺）。落地時的速度和加速度是多少？

看解法

落地代表掉了 256 英尺：$16t^2 = 256$，$t^2 = 16$，$t = 4$ 秒。

速度 $v = s' = 32t$，所以 $v(4) = 128$ 英尺/秒。加速度 $a = s'' = 32$ 英尺/秒²，是常數（這就是重力加速度）。

新聞說「成長趨緩」，講的就是 f″

商管題最愛考這種句子的翻譯。「在成長」講的是 $f' \gt 0$；「成長得越來越快或越來越慢」講的是 $f''$ 的正負。

$f'$$f''$白話圖形的樣子
正正在增加，而且越增越快（加速成長）往上走、往上彎
正負在增加，但越增越慢（成長趨緩）往上走、往下彎
負負在減少，而且越掉越快往下走、往下彎
負正在減少，但越掉越慢（跌勢趨緩）往下走、往上彎

下面是課本習題裡某開發中國家的 GDP：$G(t) = -0.2t^3 + 2.4t^2 + 60$（十億美元，$t$ 是年）。它的 $G'(t) = -0.6t^2 + 4.8t$，$G''(t) = -1.2t + 4.8$。

新聞：「房價還在漲，但漲勢已經趨緩。」設房價是 $P(t)$，這句話用導數怎麼寫？

「還在漲」是 $P' \gt 0$。「漲勢趨緩」是上漲的速度 $P'$ 在變小，也就是 $P'' \lt 0$。

計算的訣竅：每微一次，先整理再往下

  1. 根號、分母先改寫成次方（$\dfrac1x = x^{-1}$、$\sqrt{x} = x^{1/2}$）。
  2. 微完一次，先化簡（合併、提公因式），再微下一次。
  3. 如果上一行是「兩包東西相乘」，下一次就要用乘法規則；有括號的次方就要用連鎖律。

例 1（負次方）：$f(x) = \dfrac1x = x^{-1}$，求 $f'''(x)$。

$$f'(x) = -x^{-2} \qquad f''(x) = 2x^{-3} \qquad f'''(x) = -6x^{-4} = -\frac{6}{x^4}$$

次方一直搬下來乘，正負號會交替出現。

例 2（連鎖律）：$f(x) = (2x - 3)^4$，求 $f'''(x)$。裡面 $2x - 3$ 的微分是 2，每一次都要乘：

$$\begin{aligned} f'(x) &= 4(2x-3)^3\cdot 2 = 8(2x-3)^3\\ f''(x) &= 8\cdot 3(2x-3)^2\cdot 2 = 48(2x-3)^2\\ f'''(x) &= 48\cdot 2(2x-3)\cdot 2 = 192(2x-3) \end{aligned}$$

例 3（連鎖律之後要用乘法規則）：$y = (2x^2 + 3)^{3/2}$，求 $y''$。

第一次：外層 $\tfrac32$ 次方，裡面 $2x^2 + 3$ 的微分是 $4x$。

$$y' = \tfrac32(2x^2+3)^{1/2}\cdot 4x = 6x\,(2x^2+3)^{1/2}$$

現在 $y'$ 是 $6x$ 和 $(2x^2+3)^{1/2}$ 相乘，第二次要用乘法規則：

$$y'' = \underbrace{6}_{\text{前微}}(2x^2+3)^{1/2} + 6x\cdot\underbrace{\tfrac12(2x^2+3)^{-1/2}\cdot 4x}_{\text{後微}} = 6(2x^2+3)^{1/2} + \frac{12x^2}{(2x^2+3)^{1/2}}$$

通分之後：

$$y'' = \frac{6(2x^2+3) + 12x^2}{\sqrt{2x^2+3}} = \frac{24x^2 + 18}{\sqrt{2x^2+3}}$$

連鎖律微完第一次以後，前面多出來的那個 $x$（像例 3 的 $6x$）會讓式子變成「乘積」。第二次如果還只用連鎖律、忘記乘法規則，就會少一項。指定題 #28 就是考這個。

$f(x) = (3x+1)^3$，$f''(x)$ 是？

$f'(x) = 3(3x+1)^2\cdot 3 = 9(3x+1)^2$。$f''(x) = 9\cdot 2(3x+1)\cdot 3 = 54(3x+1)$。兩次都要乘裡面的微分 3。

指定題

這一節只有一題，但是它把連鎖律、乘法規則、提公因式全部用上了。先自己算到 $g''$，再對答案。

求三階導數

求函數 $g(t) = \left(\tfrac12 t^2 - 1\right)^5$ 的三階導數 $g'''(t)$。

提示

裡面那包 $\tfrac12 t^2 - 1$ 的微分是 $t$。第一次用連鎖律，之後每一行都是「兩包相乘」，要用乘法規則。每微完一次就把共同的 $\left(\tfrac12 t^2 - 1\right)$ 次方提出來，下一步會好算很多。

一階導數：連鎖律

外層是 5 次方，裡面是 $\tfrac12 t^2 - 1$，裡面的微分是 $\tfrac12\cdot 2t = t$：

$$g'(t) = 5\left(\tfrac12 t^2 - 1\right)^4\cdot t = 5t\left(\tfrac12 t^2 - 1\right)^4$$

二階導數：乘法規則

把 $g'$ 看成前面 $5t$、後面 $\left(\tfrac12 t^2 - 1\right)^4$。前面微分是 $5$；後面微分是 $4\left(\tfrac12 t^2 - 1\right)^3\cdot t$。

$$g''(t) = 5\left(\tfrac12 t^2 - 1\right)^4 + 5t\cdot 4t\left(\tfrac12 t^2 - 1\right)^3 = 5\left(\tfrac12 t^2 - 1\right)^4 + 20t^2\left(\tfrac12 t^2 - 1\right)^3$$

提公因式，把 g″ 整理乾淨

兩項都有 $5\left(\tfrac12 t^2 - 1\right)^3$，提出來：

$$g''(t) = 5\left(\tfrac12 t^2 - 1\right)^3\Big[\left(\tfrac12 t^2 - 1\right) + 4t^2\Big] = 5\left(\tfrac12 t^2 - 1\right)^3\left(\tfrac92 t^2 - 1\right)$$

中括號裡 $\tfrac12 t^2 + 4t^2 = \tfrac92 t^2$。

三階導數：再用一次乘法規則

前面 $5\left(\tfrac12 t^2 - 1\right)^3$ 的微分是 $15\left(\tfrac12 t^2 - 1\right)^2\cdot t$；後面 $\tfrac92 t^2 - 1$ 的微分是 $9t$。

$$g'''(t) = 15t\left(\tfrac12 t^2 - 1\right)^2\left(\tfrac92 t^2 - 1\right) + 5\left(\tfrac12 t^2 - 1\right)^3\cdot 9t$$

再提一次公因式

兩項都有 $15t\left(\tfrac12 t^2 - 1\right)^2$（第二項的 $45t = 15t\times 3$）：

$$\begin{aligned} g'''(t) &= 15t\left(\tfrac12 t^2 - 1\right)^2\Big[\left(\tfrac92 t^2 - 1\right) + 3\left(\tfrac12 t^2 - 1\right)\Big]\\ &= 15t\left(\tfrac12 t^2 - 1\right)^2\left(6t^2 - 4\right)\\ &= 30t\left(\tfrac12 t^2 - 1\right)^2\left(3t^2 - 2\right) \end{aligned}$$

中括號裡 $\tfrac92 t^2 + \tfrac32 t^2 = 6t^2$，$-1 - 3 = -4$；最後 $6t^2 - 4 = 2(3t^2 - 2)$。

代一個數字驗算

取 $t = 2$：$\tfrac12 t^2 - 1 = 1$，所以 $g'''(2) = 30\cdot 2\cdot 1^2\cdot(12 - 2) = 600$。用沒化簡的那一行算：$15\cdot 2\cdot 1\cdot 17 + 5\cdot 1\cdot 18 = 510 + 90 = 600$，一致。考試有時間就挑一個簡單的數字這樣檢查。

$g'''(t) = 30t\left(\tfrac12 t^2 - 1\right)^2\left(3t^2 - 2\right)$

高階導數的題目，錯通常不是錯在觀念，是錯在抄寫。每一行都把「這是幾階導數」標清楚（$g'$、$g''$、$g'''$），微完先整理再往下。答案不一定要化到最簡，但提公因式之後下一步會簡單很多，也比較不會掉項。遇到「速度、加速度」的應用題，記得答案要寫單位。
