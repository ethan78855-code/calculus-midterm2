第 5 章 · Sections 5.1–5.2

指數函數與對數函數

第 5 章的主角是 $e^x$ 和 $\ln x$。這一頁不用微分，只做三件事：把次方的規則複習好、弄懂「對數就是反過來問次方」、學會用 $\ln$ 解方程。後面的複利、微分、5.6 的指定題全部靠這一頁。

指數律：次方的運算規則

$b^x$ 讀作「$b$ 的 $x$ 次方」，$b$ 叫底數，$x$ 叫指數。底數相同時，可以用下面的規則合併：

情況規則例子
同底相乘，指數相加$b^x\cdot b^y = b^{x+y}$$2^3\cdot 2^4 = 2^7$
同底相除，指數相減$\dfrac{b^x}{b^y} = b^{x-y}$$\dfrac{3^5}{3^2} = 3^3$
次方再次方，指數相乘$(b^x)^y = b^{xy}$$(e^{2})^3 = e^{6}$
乘積的次方，各自次方$(ab)^x = a^x\,b^x$$(2x)^3 = 8x^3$
零次方$b^0 = 1$$e^0 = 1$
負次方，倒過來$b^{-x} = \dfrac{1}{b^x}$$2^{-3} = \dfrac18$
分數次方，開根號$b^{1/n} = \sqrt[n]{b}$$16^{1/2} = 4$

不用硬背。$2^3\cdot 2^4$ 就是 3 個 2 乘上 4 個 2，總共 7 個 2，所以指數相加。$(2^3)^4$ 是「3 個 2」重複 4 組，總共 12 個 2，所以指數相乘。

指數律只管乘除，不管加減。$2^3 + 2^4 \ne 2^7$，$(a+b)^2 \ne a^2 + b^2$。另外 $e^{2x}\cdot e^{3x} = e^{5x}$（相加），不是 $e^{6x^2}$。

指數函數 f(x) = bˣ

之前學的 $x^2$、$x^3$ 是變數在下面（冪函數）。指數函數反過來，變數在上面：

$$f(x) = b^x \qquad (b \gt 0,\ b \ne 1)$$

拉動滑桿改變底數 $b$，看圖形怎麼變：

  1. 定義域是所有實數，$x$ 代什麼都可以。
  2. 值域是 $(0, \infty)$：$b^x$ 永遠是正的，不會是 0，也不會是負的。
  3. 圖形通過 $(0, 1)$，因為 $b^0 = 1$。
  4. $b \gt 1$ 時遞增；$0 \lt b \lt 1$ 時遞減。
  5. $x$ 軸（$y = 0$）是水平漸近線：圖形會無限貼近，但碰不到。

第 2 點之後找極值時很好用：解 $f'(x) = 0$ 時，如果式子裡有 $e^x$ 這個因式，可以直接丟掉，因為它不可能等於 0。

$f(x) = \left(\tfrac12\right)^x$ 的圖形，下面哪個敘述正確？

底數 $\tfrac12$ 介於 0 和 1，所以遞減。所有指數函數都通過 $(0, 1)$ 而不是原點，而且值永遠是正的。

特別的底數 e

微積分幾乎只用一個底數：$e \approx 2.71828$。它跟 $\pi$ 一樣是一個固定的無理數。

$$e = \lim_{m\to\infty}\left(1 + \frac1m\right)^m \approx 2.71828$$

意思是：把 $m$ 代越來越大的數進去，$\left(1 + \frac1m\right)^m$ 會越來越接近一個固定的值，那個值就叫 $e$。按「播放」看看：

$m$101001,00010,0001,000,000
$\left(1+\frac1m\right)^m$2.593742.704812.716922.718152.71828

這個式子其實就是 5.3 節的複利：一年複利 $m$ 次，$m$ 無限大就變成「連續複利」，所以 $e$ 會出現在所有成長與衰退的模型裡。

$e^x$ 和 $e^{-x}$ 是最常見的兩條曲線，互為左右鏡射：

  1. 找到 $e^x$ 鍵。多數工程計算機印在 ln 鍵的上方，要先按 SHIFT（或 2nd）再按 ln。
  2. 算 $e^2$：按 eˣ、2、=，得到 7.389。
  3. 指數是負數或一串算式時，一定要加括號。算 $e^{-0.05\times 10}$：按 eˣ ( (−) 0.05 × 10 ) =，得到 0.6065。
  4. 要 $e$ 本身就算 $e^1$，得到 2.71828。

先拿這三個數字試機：$e^2 \approx 7.389$、$e^{-1} \approx 0.3679$、$e^{-0.5} \approx 0.6065$。按出來不一樣，就是括號或負號按錯了。

解指數方程：兩邊化成同底

如果 $b^m = b^n$，那麼 $m = n$。

例：解 $2^{2x-1} = 16$。把 16 寫成 $2^4$：

$$2^{2x-1} = 2^4 \quad\Rightarrow\quad 2x - 1 = 4 \quad\Rightarrow\quad x = \frac52$$

例：解 $9^x = 27$。兩邊都是 3 的次方：$9^x = (3^2)^x = 3^{2x}$，$27 = 3^3$，所以 $2x = 3$，$x = \tfrac32$。

如果兩邊沒辦法化成同底，例如 $e^{0.2t} = 4$，就需要下面的對數。

對數：反過來問「幾次方」

$2^3 = 8$ 是問「2 的 3 次方是多少」。對數反過來問：「2 的幾次方會是 8？」答案是 3，寫成 $\log_2 8 = 3$。

$$y = \log_b x \quad\Longleftrightarrow\quad b^y = x \qquad (x \gt 0)$$

兩個式子講同一件事，只是寫法不同。$\log_b x$ 就是「$b$ 要幾次方才會變成 $x$」。

指數的寫法對數的寫法唸法
$2^3 = 8$$\log_2 8 = 3$2 的 3 次方是 8
$10^2 = 100$$\log 100 = 2$10 的 2 次方是 100
$2^{-3} = \tfrac18$$\log_2 \tfrac18 = -3$答案可以是負的
$e^0 = 1$$\ln 1 = 0$任何底數的 0 次方都是 1
$e^1 = e$$\ln e = 1$$e$ 的 1 次方是自己

有兩個底數太常用，所以有專屬的寫法，計算機上也各有一個鍵：

$\log x$ 是以 10 為底：$\log x = \log_{10} x$（常用對數，計算機的 log 鍵）
$\ln x$ 是以 $e$ 為底：$\ln x = \log_e x$（自然對數，計算機的 ln 鍵）

對數裡面只能放正數。$\ln 0$、$\ln(-2)$ 都沒有定義，因為 $e$ 的任何次方都是正的。計算機按出 Math ERROR 通常就是這個原因。

$\log_3 81$ 等於多少？

問的是「3 的幾次方是 81」。$3^4 = 81$，所以答案是 4。

對數律

對數就是指數，所以指數律翻譯過來就是對數律。下面 $m$、$n$ 都是正數：

口訣規則例子
裡面相乘，拆成相加$\log_b (mn) = \log_b m + \log_b n$$\ln(3x) = \ln 3 + \ln x$
裡面相除，拆成相減$\log_b \dfrac{m}{n} = \log_b m - \log_b n$$\ln\dfrac{x}{2} = \ln x - \ln 2$
裡面的次方，搬到前面$\log_b m^n = n\,\log_b m$$\ln x^5 = 5\ln x$
1 的對數是 0$\log_b 1 = 0$$\ln 1 = 0$
底數自己的對數是 1$\log_b b = 1$$\ln e = 1$

第三條最重要：它能把卡在指數上的未知數「拉下來」，解方程全靠它。根號也是次方，所以 $\ln\sqrt{x} = \ln x^{1/2} = \tfrac12\ln x$。

對數律只能拆乘、除、次方，加減不能拆：

$\ln(m + n) \ne \ln m + \ln n$　　　$\dfrac{\ln m}{\ln n} \ne \ln\dfrac{m}{n}$　　　$(\ln x)^2 \ne 2\ln x$

最後一個要看清楚：$\ln x^2$ 是「裡面」平方，可以搬；$(\ln x)^2$ 是「整個對數」平方，不能搬。

把 $\ln\dfrac{x^3}{y}$ 展開，哪一個正確？

相除拆成相減：$\ln x^3 - \ln y$。再把次方 3 搬到前面：$3\ln x - \ln y$。

ln 和 e 互相抵消

$\ln$ 和 $e^x$ 是一對相反的動作，就像「平方」和「開根號」。先做一個再做另一個，會回到原來的數：

$$\ln e^x = x \qquad\qquad e^{\ln x} = x \quad (x \gt 0)$$

圖形上，$y = \ln x$ 就是把 $y = e^x$ 對著直線 $y = x$ 翻過去（$x$、$y$ 座標對調）。拉滑桿看看兩個點怎麼對應：

  1. 只定義在 $x \gt 0$（圖形只在 $y$ 軸右邊），$y$ 軸是垂直漸近線。
  2. 通過 $(1, 0)$，因為 $\ln 1 = 0$。
  3. 一直遞增，但越來越平緩。
  4. $0 \lt x \lt 1$ 時 $\ln x$ 是負的；$x \gt 1$ 時是正的。

用 ln 解方程（5.6 節一直會用）

未知數卡在 $e$ 的指數上時，取 $\ln$ 就能把它拉下來。

  1. 先把 $e$ 的那一項單獨留在一邊（係數除過去、常數移過去）。
  2. 兩邊同時取 $\ln$。左邊的 $\ln$ 和 $e$ 抵消，只剩指數。
  3. 解出未知數，最後才按計算機。

例：解 $5e^{0.2t} = 20$。

$$e^{0.2t} = 4 \quad\Rightarrow\quad \ln e^{0.2t} = \ln 4 \quad\Rightarrow\quad 0.2t = \ln 4 \quad\Rightarrow\quad t = \frac{\ln 4}{0.2} \approx \frac{1.3863}{0.2} \approx 6.93$$

第 1 步不能跳過。$5e^{0.2t} = 20$ 如果直接取 $\ln$，左邊是 $\ln 5 + 0.2t$，不是 $5\times 0.2t$。先除以 5 再取 $\ln$ 最不容易錯。

反過來，未知數在 $\ln$ 裡面：解 $5\ln x + 3 = 0$。先把 $\ln x$ 單獨留下，再兩邊取 $e$ 的次方：

$$\ln x = -0.6 \quad\Rightarrow\quad x = e^{-0.6} \approx 0.5488$$

底數不是 $e$ 也一樣：解 $2^x = 10$。兩邊取 $\ln$，把 $x$ 搬下來：

$$x\ln 2 = \ln 10 \quad\Rightarrow\quad x = \frac{\ln 10}{\ln 2} \approx \frac{2.3026}{0.6931} \approx 3.32$$
  1. ln 鍵算自然對數：按 ln 4 = 得 1.3863。log 鍵是以 10 為底：按 log 100 = 得 2。兩個鍵不要按錯。
  2. 算 $\dfrac{\ln 4}{0.2}$：按 ln 4 ) ÷ 0.2 =。有些機型按 ln 會自動出現左括號，記得把右括號補上，再按除號。
  3. 算 $\dfrac{\ln 10}{\ln 2}$：按 ln 10 ) ÷ ln 2 ) =。分子分母各自用括號收好。
  4. 中間的小數不要抄到紙上再重新輸入。一次按完，或用 Ans 鍵接著算，最後才四捨五入。

解 $200e^{-0.05t} = 100$ 的第一步應該是什麼？

先讓 $e$ 的那一項單獨留下。接著取 $\ln$：$-0.05t = \ln 0.5$，所以 $t = \dfrac{\ln 0.5}{-0.05} \approx 13.86$。

例題

這兩節沒有指定題，但第 5 章後面每一題都會用到這些動作。先自己算，再一步一步打開。

例題 1：用指數律化簡

化簡：(a) $16^{3/4}$　(b) $\dfrac{3^5\cdot 3^{-2}}{3^2}$　(c) $(e^{2x})^3\cdot e^{-x}$

(a) 分數次方：先開根號再次方

$$16^{3/4} = \left(16^{1/4}\right)^3 = 2^3 = 8$$

$16 = 2^4$，所以開 4 次方根是 2。

(b) 同底：乘是加、除是減

$$\frac{3^5\cdot 3^{-2}}{3^2} = 3^{5 + (-2) - 2} = 3^1 = 3$$

(c) 先處理次方的次方

$$(e^{2x})^3\cdot e^{-x} = e^{6x}\cdot e^{-x} = e^{6x - x} = e^{5x}$$

(a) 8　(b) 3　(c) $e^{5x}$

例題 2：化成同底解方程

解 $3^{x - x^2} = \dfrac{1}{9^x}$。

提示

$9 = 3^2$，而且「在分母」等於「負次方」。把右邊也寫成 3 的次方。

右邊改寫成 3 的次方

$$\frac{1}{9^x} = \frac{1}{(3^2)^x} = \frac{1}{3^{2x}} = 3^{-2x}$$

同底，指數相等

$$3^{x - x^2} = 3^{-2x} \quad\Rightarrow\quad x - x^2 = -2x$$

解二次方程

$$x^2 - 3x = 0 \quad\Rightarrow\quad x(x - 3) = 0 \quad\Rightarrow\quad x = 0 \ \text{或}\ x = 3$$

驗算 $x = 3$：左邊 $3^{3-9} = 3^{-6}$，右邊 $\dfrac{1}{9^3} = 3^{-6}$ ✓。

$x = 0$ 或 $x = 3$

例題 3：展開與合併對數

(a) 展開 $\ln\dfrac{x^2\sqrt{x+1}}{e^x}$。
(b) 把 $2\ln x - \tfrac12\ln(x+1) + \ln 3$ 合併成一個對數。

(a) 乘變加、除變減

$$\ln\frac{x^2\sqrt{x+1}}{e^x} = \ln x^2 + \ln (x+1)^{1/2} - \ln e^x$$

(a) 次方搬到前面，ln 和 e 抵消

$$= 2\ln x + \tfrac12\ln(x+1) - x$$

注意 $\ln(x+1)$ 不能再拆成 $\ln x + \ln 1$，裡面是加法就到此為止。

(b) 反過來做：係數搬回去當次方

$$2\ln x - \tfrac12\ln(x+1) + \ln 3 = \ln x^2 - \ln\sqrt{x+1} + \ln 3$$

(b) 加變乘、減變除

$$= \ln\frac{3x^2}{\sqrt{x+1}}$$

(a) $2\ln x + \tfrac12\ln(x+1) - x$　(b) $\ln\dfrac{3x^2}{\sqrt{x+1}}$

例題 4：用 ln 解指數方程

解 $4e^{x-1} = 10$，答案四捨五入到小數第三位。

把 e 的那一項單獨留下

$$e^{x-1} = \frac{10}{4} = 2.5$$

兩邊取 ln

$$x - 1 = \ln 2.5$$

解出 x，再按計算機

$$x = 1 + \ln 2.5 \approx 1 + 0.9163 = 1.916$$

$x = 1 + \ln 2.5 \approx 1.916$

例題 5：應用題裡反求時間

速記課的學生第 $t$ 週每分鐘能記 $Q(t) = 120\left(1 - e^{-0.05t}\right) + 60$ 個字（這是指定題 5.6 #16 的函數）。第幾週可以達到每分鐘 100 個字？

提示

令 $Q(t) = 100$。一層一層剝：先減 60，再除以 120，把 $e^{-0.05t}$ 單獨留下之後才取 $\ln$。

列式，一層一層剝開

$$120\left(1 - e^{-0.05t}\right) + 60 = 100 \quad\Rightarrow\quad 1 - e^{-0.05t} = \frac{40}{120} = \frac13$$

把 e 的那一項單獨留下

$$e^{-0.05t} = 1 - \frac13 = \frac23$$

取 ln，解 t

$$-0.05t = \ln\frac23 \quad\Rightarrow\quad t = \frac{\ln\frac23}{-0.05} \approx \frac{-0.4055}{-0.05} \approx 8.1$$

$\ln\tfrac23$ 是負的（因為 $\tfrac23 \lt 1$），除以 $-0.05$ 剛好負負得正。算出負的時間就代表哪裡的正負號掉了。

這兩節在考卷上通常不會單獨出大題，而是藏在每一題的最後一步。最常掉分的三個地方：把 $\ln(a+b)$ 拆開、沒有先把 $e$ 的那一項單獨留下就取 $\ln$、計算機的負指數沒加括號。考前拿 $e^{-0.5} \approx 0.6065$ 和 $\ln 4 \approx 1.3863$ 試一次自己的計算機。
